# 产品边界

作品：《重返木卫三》。中文原创单人第一人称射击战役，双主角，序章／占领区／通路／下一班／尾声；12 段、10 组遭遇，首通目标 55—70 分钟，实际时长待测。

targetFinish: 可完整游玩的比赛作品，具有一致美术与声音、可恢复的战役进度及 Windows EXE；首轮 whitebox 不冒充成品。

targetPlatform: Windows 桌面；Mac 是开发与浏览器验证环境。targetRuntime: Three.js + 桌面容器（Electron 候选）；浏览器用于开发验证，不替代 Windows 实机验收。显示横屏，键盘鼠标，基准 1920×1080，兼顾 1366×768。单人离线运行，不要求移动端、联网、多人或账号。

experienceProfile: hybrid，实时射击与固定叙事协作相连。战争伤亡采用克制表达，不依赖血腥猎奇。用户授权先用程序化占位、按模块持续制作；保留完整故事及三条验证线。
