# UI 方向：冷灰军事界面与明确战斗反馈

2026-10-31 用户指定全部 UI／HUD 以《使命召唤：现代战争》系列为表现参考。本作采用其清晰信息层级、克制军事面板和快速战斗确认的方向，保持原创排版、文字、图形与资产。本轮建立命中反馈及战斗 HUD 的风格基准；菜单、字幕、完整界面与交互演出的后续精修继续按此方向推进。

## 本轮基准

- 常规信息使用冷灰与近白；面板为低饱和深灰，边界采用细线，保留战斗画面的可见面积。
- 当前目标、生命与弹药按现有位置呈现。弹匣数字明显大于备用弹药，使用等宽数字与稳定最小宽度。
- 普通敌人命中弹出白色叉，击杀弹出红色叉；重叠时红色优先，透明度取有效反馈的较大值。无事件或不在游玩状态时隐藏。
- 叉形由现有四段 CSS 线条与 45° 旋转形成。深色细阴影保证亮、暗场景可读；中心留空，反馈不增加说明文字。
- 低生命／空弹仍保留原有暖色警示语义。红色命中叉明确表示击杀，不能用普通射击、开火事件或击中友军触发。
- 不新增命中反馈动画时钟；仿真提供命中与击杀的衰减强度，界面仅映射颜色和透明度。暂停立即隐藏，恢复时遵循仿真状态。

## 代码接口与范围

`src/ui/HitConfirmation.ts` 导出纯函数 `hitConfirmation(hitFlash, killFlash, playing)`，返回 `{ opacity, color }`。输入限制为 0—1，非有限数与负数按零处理。`GameUI` 将返回值写入现有 `.hit-marker` 父节点的 `opacity` 和 `color`，四个子线段使用 `currentColor`。

`src/ui/modern-combat.css` 在基础 `style.css` 之后导入，覆盖命中叉及选定 HUD 元素的色彩、细线、数字层级。当前布局、控件行为、字幕、手持道具、菜单结构与动作流程由原模块保持管理；新样式不修改全局色板，避免连带改变这些区域。

本轮全部视觉由项目 CSS 绘制，不包含《现代战争》的商标、截图、纹理、字体文件或其他外部美术资产。界面参考不意味着复制其完整布局。

## 验收范围

逻辑回归覆盖白色命中、红色击杀优先级、无事件隐藏、暂停隐藏、异常数值和反馈结束后的颜色复位。集成验收还需在桌面实际游戏画面确认普通命中与击杀来自弹丸结果，以及明亮背景、ADS、暂停和重试时的可读性与清理。

后续整体 UI 精修沿用此基准，并单独验收字幕节奏、菜单层级、交互动作与目标指示；本轮样式落地不代表这些项目已经完成。
