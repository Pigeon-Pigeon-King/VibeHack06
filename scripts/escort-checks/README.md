# S08 / S09 场地检查

从项目根目录运行：

```sh
npx vitest run --config scripts/escort-checks/vitest.config.ts --disableConsoleIntercept
```

这些 `.check.ts` 使用实际环境碰撞、`Physics` 和 `Navigation`，通过 `Physics.move` 连续移动独立检查夹具；不推进任务、不改任务事实伪造通关，不属于浏览器或真人验收。命名与独立配置使其不混入正式 `npm test` 的任务回放数量。

当前 10 项检查覆盖：任务/NPC/完整患者车初位净空；开启货运门后的三段车道；两处真实桥面；2.4 米平台上下楼梯；步行陪护与玩家工作点；第二患者车绕过留存旧床的实际路线及逐帧床体间距；接防人员、工人和郑铎实际路线；任务到位容差；敌人入口到阵位的真实导航；眼点与保守枪口射线；运输遮护及休息位保护；静态几何统计。
