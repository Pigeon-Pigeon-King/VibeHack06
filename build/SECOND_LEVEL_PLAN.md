# S06—S07 实施约定

这是 0.4 开发计划，完成状态以验证记录为准。来源为原交接第 7／8 章和 `game_design.md` 的 S06／S07 卡；原交接不改写。

- S06 视点为陆闻川。联络员的正常道路更新让他获知转移时段和周延此前知情；两个短动作检修控制盒、释放锁杆。三辆载有患者的代理车以真实物理路径通过，许岚跟随本批离开。患者通过后才进入设备间，双方收枪，约 70 秒固定争执可跳过。随后处理手伤、随罗敬继续工作。没有敌军、密码谜题、长按读条或限时救治。
- S07 视点为周延。由检修台经泵房外侧转到储罐基座、内门；东侧和北车道入场有预告，上限八名活动敌人、两名同时瞄准者，E05 入场上限 44。人数只是压力预算，推进取决于射界安全、技工和同伴真正撤回。
- 安全间隙采用孟齐已踏勘的分流建议：患者车走货廊，可步行者走旁侧的短梯与跨接板；不能把患者车送上梯道。真实通行反馈后，周延承认扣住预告，发送已核实／未核实信息、来源和时间、人力与接应成本；然后提出休息和接替，将自己列入撤回名单。

共享实现：稳定 Actor ID；患者车带独立长方体碰撞、车距和宽度更大的导航；原本的胶囊人物保持原行为。检查点保存路线、每车到达状态、门、阶段与人物知识。沿用 S05 的地理方向、南侧内门和西侧通道。非战斗区有实体遮护，进入安静段前检查实际威胁。

验证重点：正常和跳过的任务终态一致；门打开前不得穿越、打开后物理和导航同时更新；患者车和步行者实际移动且不互换路线；争执不能先于患者通过；S05 的私有知识不提前赋予闻川；跨章与检查点恢复不丢角色或重复执行；旧八场景存档继续可用。公开 Intent 回放、浏览器操作和 Windows 实机分别记录，不相互替代。

本轮仍允许方块人物、程序化工业环境和患者车代理。接触动作、语音、正式模型、Windows 运行和全战役时长不因这些代理测试通过而被标为完成。
