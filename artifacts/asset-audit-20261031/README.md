## 结论

用户看到的是当前代码中确实存在的白盒。根因是**已生产资产只接入了部分实例，大量环境构造器和剧情道具仍走程序化模型**。不是资源下载缺失，也不是远景 LOD 切回了白盒。此前“60 个资产都接入”的说法混淆了型号目录引用与全部场景实例覆盖。

60 个独立生产模型为 13 个人物、25 件 Tripo 道具、22 件地图/建筑构件。人物身体、道具源/运行文件及地图目录路径已核对；文件存在、代码绑定、原物隐藏、实际画面通过是四种不同证据。本轮没有新增浏览器或 Windows 实机验收。

## 已生产但未完成接入

- 25 件道具中，仅 7 个 ID 进入原物替换槽，18 个只是新增陈列或背景。跨场景有 56 次摆放、22 次替换槽实例；这些数都不是全部物体覆盖率。
- S04 卡车仍是盒体；现有运输车只摆在 S05 边界外。通勤巴士与军用运输车外形不同，不能只换名字宣布都完成。
- 所有剧情 `role=cart` 走程序化患者车。已有转运车、担架仅静态陈列；患者、推车者、坏轮、换车、抬人状态没有接生产模型。
- 已有门叶、门锁、风扇、午餐盒、货箱、医疗支具，没有全部连接到原来的事实显隐、开关、搬运与接触动作。
- 13 个人物身体已接普通角色和群众。S08 监控邵原、S10/S11 床上具名伤员、搬运/护理手部仍旧；第一人称持枪双臂已是真实蒙皮裁切，不能误报为全未接。
- AK47 已用于持枪角色，但第三人称仍挂旧代理枪节点；历史厅散落的三把枪仍为几何体。
- 每人战术包有 17 片段：运行选择 5 个，行走用独立 canonical；11 个蹲起/掩体/观察/瞄准/开火片段未触发，另一个包内 walk 重复片段未用。SHAO、DOCTOR、SHEN、儿童为稳定性暂跳过战术包。

## 尚缺专用资产或适配

优先复用现有基模，不扩大人物数量。下列不是同一类“未生产”问题：

| 类型 | 当前缺口 | 应做的工作 |
|---|---|---|
| 基模已有，缺接入 | 地墙顶梁、路障、箱、罐、灯、拖车、终端、长椅、柜子、AK、具名患者 | 按所有真实实例绑定，保留碰撞、导航、身份与剧情 |
| 基模已有，缺分件/状态/挂点 | 门锁控制器、开门、转运车/担架接触、风机转子、开盖餐盒、护具穿戴 | 从原件准备分件和枢轴并接状态，静态摆件不算完成 |
| 当前生成库无对应专用形体 | 枕头/床垫/毯子、输液架/袋/管、医疗帘、洗手池/水龙头/敷料、部分桌架、瓶/桌面电台、散装冰芯 | 先核查可用模块与概念图，再按明确需求补产；不以相似名称冒充 |
| 地图专用构件/变体未具备 | 浅弧棚/温室、楼梯/栏杆、可断裂屋面、宽闸门、通勤巴士等 | 核对尺寸和功能，适用模块装配或补相符生产件 |
| 动作缺口 | 搬运/护理/抱撤/扶门/换弹/受击/死亡的专用接触片段 | 与现有 17 个战术片段分开登记，人物基模无需重复生产 |

女孩与儿童陆闻川、年轻与中年周延、群众皮肤的复用属于当前复用边界；本审计不要求为此新增一批人物。独立手枪缺失由用户“统一 AK47”决定覆盖，不列为本轮必产。

## 其他可见层和加载路径

HUD、字幕、交互提示、准星、道路标记、灯光、弹道/火花与不可见碰撞分开登记，不把它们计为物理模型替换。Jupiter 是程序化可见天体，当前仍没有生成天空资产；不悄悄计入已完成。

S12 F-35B 使用用户已授权复用的原网格数值与机构，是有来源的保留网格工厂，并非临时盒体，也不是 Tripo/Hyper 生产；来源见 `docs/REUSE_MILITARY_AIR_ASSETS.md`。

`GeneratedArchitecture` 成功后只在生成 LOD 间切换，不会远距恢复白盒。`GeneratedSceneAssets` 只有整槽全部成功才隐藏旧物。加载失败可降级进入游戏，`main.ts` 会提示“部分场景素材未能载入，已保留临时模型”。本轮发现的零覆盖场景即使全部下载成功也不会改变。
