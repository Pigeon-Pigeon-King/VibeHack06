## 回归口径修正

提速后，几个旧测试的时间假设不再成立，已保持行为约束并调整观察方法：足够长的入场路线中验证边走边射击；在真正到达的那一帧验证终点，避免把随后正常战术换位算成偏离；Q 按可用阶段入口触发；S08 按每段演出起止严格核对生命、弹药和储备，允许实际交火造成不同的终态耗弹。活敌撤出存读另用明确标注的合成初态，仍要求它真实走到既有出口、活着退场、恢复后不复活。

最后一次旧检查失败并非郑铎没有伤害：统计只登记开局敌人，漏掉后来增援。只读 [Q 弹道诊断](q-cover-diagnostic.json) 在候选 `19437e2` 记录两次真实命中，新增敌人生命 **68 → 51 → 34**，玩家未开枪。正式测试现于每步前登记新增敌人，再检查真实生命下降；没有注入伤害、保证命中或改瞄准算法。保留的 [诊断脚本](q-cover-diagnostic.check.ts) 和 [独立配置](q-cover-diagnostic.config.ts) 刻意复现旧统计断言，手动运行该历史诊断预期为 FAIL，不属于上表正式回归。
