## 核心安排

- 规格目标：45.000 秒，1920×1080、30 fps、1,350 帧；具体录制能力到制作时核对。
- 11 个镜头段；41—45 秒留作完整标题，旁白在 41 秒前结束。
- 以成年闻川旁白连接十年等待、旧仇、追击机会与护送承诺。背景含蓄表达，社会制度名词不放进字幕或配音。
- 片中不讲制作工具；技术与 AI 创作理念由前面的宣讲承担。
- 画面来自同一冻结构建中的实机演出／操作。新增取景需求先在游戏里完成，记录原片与来源；本文件不代表画面已经存在或通过验收。

## 3. 原创 45 秒配乐制作单

**方向：寒冷的工业电子战斗音乐，逐渐收紧的节奏中保留一条短小的人性主题。** 可参考《赛博朋克 2077》的失真合成低音、金属打击与机械推进感；旋律、和声动机、声音素材及整体编排独立创作。美术标题保持本作自己的工业气质，不直接套用该作字形与配色。

建议作曲网格：**128 BPM，4/4 拍，24 小节，恰好 45 秒**。

`24 小节 × 4 拍 × 60 ÷ 128 BPM = 45.000 秒`。保持速度，通过鼓点细分、低音层次和音色密度逐步紧凑；并非全程只加大音量。

| 时间／小节 | 编排 |
| --- | --- |
| 00—07.5 秒／1—4 | 低频持续音、稀疏金属脉冲、短主题；给风声与第一句旁白空间 |
| 07.5—15 秒／5—8 | 增加失真低音与半拍鼓感，人物出现时形成可记住的短动机 |
| 15—26.25 秒／9—14 | 鼓组展开，战斗推进；“追上去，还来得及”前局部抽掉一层节奏 |
| 26.25—37.5 秒／15—20 | 增加切分与细分；交接／搬运时短暂减少低频和高频噪声，保留真实动作声 |
| 37.5—41.25 秒／21—22 | 最后一层上升，主题回应；不要盖住“这扇门” |
| 41.25—45 秒／23—24 | 标题已出现后落下终止重音，留尾响，45 秒内完全收束 |

交付建议为 48 kHz、24-bit、立体声 WAV 母带，45 秒 PCM 每声道应有 **2,160,000 个采样帧**。若先由生成模型给出音乐草稿，仍需编曲／剪辑到实际长度，不能只因提示词写了“45 秒”就确认合格。最终文件按听感与波形检查收尾；不要在第 45 秒才落最后一下重音。

先保留纯音乐母带，再混入旁白与实机声音；不同播放设备试听，以旁白可懂、枪声有力但不过载为准。交付时保存可调整工程或分组音轨，便于后续换旁白而不重新做整首音乐。

## 4. 实机录音与后期分轨

已只读核对 [Sound.ts](../../../src/presentation/Sound.ts)：底层有 `sfx / voice / music / ambience` 独立总线及 `setGroupVolume`。读取时 UI 只有总音量，未找到该独立接口的调用入口；也没有现成四轨导出功能。因此以下为待接入的录制预设，不称菜单现在已经支持。

| 轨道 | 录制／后期处理 |
| --- | --- |
| 原游戏音乐 | 录制预设设 `music=0`，保留主音量。不能整体静音后靠假枪声补回 |
| 实机效果音与环境 | 保留 `sfx` 与 `ambience`；开火、爆炸、命中、脚步等跟随实际事件。需要时另录干净环境底 |
| 原游戏对白 | 新旁白版本建议录制时 `voice=0`；确有必要的短句另录并单独选用，避免与闻川旁白争抢 |
| 新音乐 | 后期独立轨；可局部降低音量／频段为旁白和关键实机声让位 |
| 新闻川旁白 | 独立干声轨；按句调整停顿，不统一快放凑时长 |

后期至少分开保留音乐、旁白、实机 SFX／环境、选用游戏对白四组。游戏的四条运行总线只是控制基础，不等于四份可直接导出的录音。任何录制入口修改由运行／声音负责人接入并试听，本轮没有修改 `Sound.ts` 或设置界面。

## 5. 可复用透明标题的 ImageGen 制作单

**唯一文字：重返木卫三。** 目标为横排五字、原创工业科幻字标：笔画厚实清楚，带克制的金属切面、磨损与接缝；冷白／钢灰主体，少量工作灯暖色。既能立在寒冷港区上，也能放在纯深色背景中。人情温度由少量暖色和留白表达，不堆头盔、枪械、地球、木星等插画。

后续 ImageGen 必须使用真实透明背景选项，输出 **RGBA PNG**。透明区域不能是画进图片的棋盘格。母版以约 3:1 的横向布局、足够用于 1080p／更高分辨率展示的尺寸为目标；具体像素依据生成能力核对，不把建议尺寸当既有输出。

检查项：

1. 五个汉字逐字正确，无多字、乱码或残缺笔画；缩小后仍能迅速读出。
2. 四周留足安全边距；字形完整，无裁切、强光淹没或细碎描边。
3. 在深色、浅色和港区实机背景上各试一次，检查真实 Alpha、白边／黑边与半透明杂色。
4. 保留无背景母版和实际生成记录；视频、游戏菜单、HTML 都引用同一版本，背景及出现动画由各处单独处理。
5. 不把副标题、日期、旁白字幕或配乐信息烘焙到标题里。

建议资产 ID 为 `BRAND-TITLE-01`；原始版未来放入项目内 `assets/source/branding/`，运行衍生版交由整合窗口按实际加载目录接入。本轮只交需求，不创建标题图片、不修改游戏菜单。

## 6. 制作完成后检查什么

- 以锁定构建登记 11 段原片：文件、入出点、场景、视点、真人输入／演出／检查点恢复方式。不存在的镜头不得标记已拍。
- 查看全片的因果：闻川仍有追击机会；周延先接受保护；没有将多人协作剪成一个人完成；片尾是接收开始。
- 实机素材无原 BGM 串入；闻川声线一致、旁白清楚；枪声与命中对应原始事件；耳机和演示设备都听过。
- 图像为真透明，片名准确，41—45 秒持续可读，结尾不突然切断音乐。
- 实测视频 1,350 帧／30 fps；检查音轨可听内容和时间戳，使成片为 45.000 秒。压缩音频封装的填充不代替实际播放长度检查。
- 试听确认后才从实际录音生成／校准字幕，保留无字幕母版。SRT 时码与本轮 JSON 的草案提示区分。
