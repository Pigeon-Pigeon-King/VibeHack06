## 时间与画面规范

本稿固定 **1920×1080、16:9、30 fps non-drop、1,350 帧＝45.000 秒**。时码采用 HH:MM:SS:FF，出点不包含该帧；第一帧0，最后一帧1349，结束边界1350。录制优先60 fps，剪辑保持正常速度，以正常抽帧进入30 fps时间线，不慢放／快放来伪造动作因果。48 kHz PCM 母带为2,160,000样本；最终编码器音频填充需另查，不能仅凭时间线说导出文件准确。

原分镜大段：5.5＋2.5＋6＋4＋4＋4＋4＋3＋5＋4.5＋2.5＝45 秒。本执行表细分16镜，总时长相同。SH02 是刻意安排的0.7秒黑场，不应被误判为意外黑帧。片名从42.5到45秒完整保留2.5秒。

每条真实游戏源片前后至少多录3秒。raw原片保留HUD／开发诊断／真实输入来源；成片可选简洁画面，但不能用后制遮蔽失败、合成不存在的命中或把自动回放标为人工玩法。当前 DEV 构建始终显示开发诊断，源码未发现已验证的“隐藏HUD”或自由摄像快捷键；干净录制入口、第三人称近景与拍摄锚点属于待整合拍摄能力，不能在操作卡里凭空填快捷键。

全部游戏画面必须来自同一冻结、已整合构建。正常第一人称片段标为“实机玩法录制”；侧拍与固定动作标为“引擎内镜头”；黑场和片名属于剪辑元素。概念图、脚本、历史白盒截图、离线渲染、AI视频不进入此成片当作实机。保留用户已授权的GLB与音频生产路线，本任务不新建美术或替换资产。

## 声音与素材交接

先按5条已定文本做无音乐粗剪并试听；A02的4.9秒和A03的1.6秒只是待试时间槽。若真实表演放不下，先调整相邻J-cut／L-cut与镜头切点、保持45秒边界，再由负责人确认文字修订；不统一快放人声、不自行删用户词句。

声音窗口已有音乐／非对白音效与角色试听准备，prepared不代表关卡、动作同步或宣传片混音完成。只读 [全战役声音接入交接](../../design/audio/production-01/runtime/INTEGRATION_HANDOFF.md)；本任务不写声音目录。宣传片保留 dialogue／effects／music 三轨，使用 trailer45.* lineId 与独立音乐cue版本，保留原游戏母带。开火、弹着、抓握、车轮必须对应真实可见事件；不得用后加音效制造不存在的动作成功。

只在SH15确有对应舰体时加入远处引擎。备用候选的两架F-35B是外围护航，不能称登陆艇、运输交接或用户要求的轨道空降舱。其机体可见性在读取的候选证据中仍未通过，因此既不能补足此镜头，也不能按“已整合军机镜头”排入完成片。

## 交付检查与复算

在仓库根目录运行：

~~~sh
python3 artifacts/trailer-45s/validate_delivery.py --write
python3 artifacts/trailer-45s/validate_delivery.py
~~~

脚本从timeline.json复建CSV／SRT／VTT，校验镜头首尾连续、1,350帧、45,000ms、片名75帧、受保护台词原文、字幕可解析／一致／有序、7候选被排除，以及 [180秒路演](../../docs/submission/ROADSHOW_3MIN.md) 的时间分配，并把源文件摘要存入 [validation.json](validation.json)。这不验证实际视频、音频自然度、演员动作、人工玩法或投影可读性。

备演路线另做1项独立轻量几何检查并通过，记录在 [rehearsal-geometry.json](rehearsal-geometry.json) 与 [运行说明](rehearsal-geometry-run.json)。它使用原生挡墙、原有检查点与公开输入，无障碍注入／任务事实改写；能受阻、退让、到达硬遮护且搬运不发射。它不是影片素材、浏览器渲染证据或95秒真人排练，不把同机负载下的测试墙钟耗时当作玩法时长。

后续只有在素材齐备时才执行：登记所有raw源片→无音乐粗剪→锁对白→混音→字幕对齐→导出带字幕MP4与无字幕母版→整片正常速度观看→ffprobe核对帧数、时长、1920×1080、30/1、音频采样率→投影／扬声器听审。保留源片、构建摘要、三轨声音与最终文件摘要。现在 final_video 为 null，相关检查一律 NOT_RUN，不生成空壳MP4充数。
