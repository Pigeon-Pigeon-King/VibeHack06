本批解决的是已产资产在真实实例上的接线缺口。没有新增或覆盖任何 GLB，没有扩大13个人物名单，没有提交新的付费生成任务。**尚未达到“所有可见物件都已生产并完成验收”。**

## 尚未生产、未适配和未验收

- **需专用来源或经过检查的源网格衍生**：松散床垫、枕头、输液架/袋/管、医疗帘、水槽/龙头、饮水瓶、绷带、餐食内容物、裸露冰芯；地图还有窗/温室玻璃、细缆/吊钩及平冰岸等。已产医疗包不能冒充输液架，闭合样本匣不能冒充裸冰芯。
- **基模已有但机械/接触适配未齐**：风机叶轮、餐盒开盖、生成车轮、倾倒浅柜/脱落门、刚性护具的活动连接与多人搬运接触。当前整机静态、整体门叶或整体护具不能计为完整机械动画。
- **地图余项**：S04架构层仍有14个primitive（12窗片、1温室玻璃、1吊机缆线）。逐场景剩余项有源码行、矩阵、条件显隐及分类，见[架构交接](architecture-handoff.md)与[完整清单](architecture-remaining.json)。某入口该计数为0仅表示该PortKit扫描无余项，不能推导整个画面无旧物。
- **其他可见层**：HUD/文字/路标/发光反馈不作为实体道具重产。程序化木星天空仍在；F-35B是此前授权复用的有来源网格工厂，不是Tripo/Hyper产出。均未偷偷计成这批生成资产。
- **运行成本**：S04全场景统一LOD2上界约303万三角、261个单级批次；S08约430万、428批次；这些尚未视锥剔除，也不含人物、道具和阴影，不能视为实测帧率。实际设备性能需要补测。

专用物件的生产/复用裁决见[道具余项](remaining-props.md)。本次优先把已有资产接到正确物件，缺产项仍公开列出。
