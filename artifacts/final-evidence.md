# 首轮白盒验证记录

候选标识：`whitebox-2026-10-31`。这是当前仓库新建的三个机制验证场景，不是交接包中的旧 Windows 原型，也不是完整战役验收。长期目标仍在推进。

## 当前结论

Three.js 真实画面、键盘移动／射击／交互、任务事实推进、检查点重试与三个场景的终态已有证据。Windows x64 便携目录已在 Mac 构建；**Windows 实机输入、音频、性能与启动仍为 NOT_RUN**。内嵌浏览器拒绝 Pointer Lock，测试使用公开的方向键／F 替代输入；不能据此宣称鼠标观察与瞄准已验证。Mac 原生应用测试因电脑锁屏未完成。

## 可复查的自动验证

`npm test -- --reporter=json --outputFile=artifacts/test-results.json`：20 项通过，0 项失败，4 个测试文件。报告见 [test-results.json](test-results.json)。

| 测试 | 证明的范围 |
| --- | --- |
| `tests/physics-ballistics.test.ts` | 飞行弹丸不会在发射时直接扣血；高速薄墙拦截；空中蹲伏不重置下降速度；头顶阻挡站起 |
| `tests/navigation.test.ts` | 网格绕障、不可穿对角狭缝 |
| `tests/mission-state.test.ts` | 低掩体枪口阻挡、撤离与岗位事实门槛、快照恢复、正常／跳过的语义终态、剧情结局不等于战斗失败 |
| `tests/scenario-paths.test.ts` | 用实际场景碰撞体、Rapier 与输入意图走完 V2、V1 正常及跳过、V3；记录 NPC 的实际路径与先后事实 |

场景回放不直接改写人物位置、生命、任务阶段或事实，但测试机器人可以读取世界状态并精确瞄准。因此它证明路径和状态可达，不证明真人难度、节奏、趣味或完整叙事时长。单元测试中的专门反例允许构造局部状态，与整段输入回放分开。

`npm run build` 完成 TypeScript 检查和生产构建。JS 入口约 4.99 MB，gzip 约 1.84 MB；Rapier compat 将 WASM 随包带入，仍有大块警告，尚未完成拆包和低端机优化。开发诊断不进入生产界面。

## 桌面与离线包

`npm run package:win` 先构建网页，再生成 `release/ReturnToGanymede-win32-x64/`。`ReturnToGanymede.exe` 已识别为 Windows x86-64 PE；目录约 362 MB，主要包含 Electron 运行时。必须保留整个文件夹，不是一个可单独拷走的 EXE，也尚非安装程序。

应用包仅装入 `dist`、`desktop`、最小 package 信息及 Three.js／Rapier 许可，不装入交接原件、完整源码、依赖开发目录或本机军事资产库。资源从本地 `game://local` 加载，渲染进程禁用 Node、启用 sandbox 与 contextIsolation，外部导航／新窗口被拒绝。构建散列见 [build-manifest.json](build-manifest.json)。签名、安装、Windows 首启／全屏／锁鼠标／音频／退出与性能仍待目标电脑验证。

## 尚不能声称完成的内容

- 三场白盒仅是缩短的机制链；完整 S01—S12、E00—E09、一小时首通和正式剧情节奏尚未实现。
- V1 尚缺父亲送走孩子后取枪牺牲、赵启明被俘与处决、坍塌／失守等完整镜头和行动；当前段落结束不是对原作情节的改写。
- V3 的信息、成长和受伤以简化台词／事实标记呈现。接护具、家人来信、多人扶抱、担架碰撞、医护真实接触均未达到正式表演；搬运期间敌军射击暂停，完整受掩护搬运的战术风险尚待制作。剧情伤势不由战斗生命条数值表达。
- 当前使用项目内程序化占位人物、场景、武器及合成临时音效，无正式 ImageGen 概念图、Tripo／Hyper3D 模型、Dot 建模交付、录制台词或外部模型集成。
- 碰撞为简化盒与胶囊，敌军 AI 与静态网格导航仍属白盒；友军不会被误射杀死，不能因此省略后续协作与敌军战术设计。
- 检查点与设置目前只在当前进程内保存；没有磁盘持久存档、版本迁移或退出恢复。武器枪口仍是物理代理，最终骨骼枪口与动画需要对齐。
- 尚无长时间资源增长、正式无障碍、Windows 硬件矩阵或真人可玩性验收；完整作品交付状态保持未完成。
