# 重返木卫三

《重返木卫三》是一款科幻题材、双主角视角的线性剧情第一人称射击游戏，以原创方块人物和工业殖民地场景，讲述一场撤离行动中关于信任、责任与相互扶持的故事。

木星悬在冰冷的天际，港区的警报打断了又一个普通的工作日。北闸失守在即，工人和居民仍被困在交火区。年轻的陆闻川与战士周延必须穿过工业通道、桥下货运带和临时救护点，为身后的人守住一条撤离路线。十年前避难所里的枪声尚未远去，这一次，他们能否把彼此带回去？

玩家将交替经历两位主人公的线性故事，在掩体间交战，与同伴配合掩护、接应撤离者并转移伤员。战场上的推进不仅取决于枪法，也取决于你是否愿意停下来，为另一个人留出脱离危险的机会。

当前提供比赛测试版本，支持电脑键鼠与手机横屏触控；部分场景与动作仍在持续完善。
