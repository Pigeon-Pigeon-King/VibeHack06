# 连续章节候选验证记录 · 0.2.0

本页是 0.2.0 历史记录；当前版本见 [0.3 验证](opening-evidence.md)。候选标识 `chapter-preview-2026-10-31`。这版新增 S03→S04 的可玩前段、持久检查点和设置；旧三白盒保留独立入口。它不是完整一小时战役或最终比赛提交。原始交接文件未改写，首轮证据另存于 [历史记录](final-evidence.md)。

## 已实现的实际流程

S03 在维修廊、护理后勤和旧样本室之间连续行动：拆掉风机堵塞物、复位并恢复转动与临时机械声、取箱、双手搬到许岚的交接台、在港图前确定共享情报与护送后接防、领装备、走到出发口。正常短对话与 Enter 跳过保持相同事实，工作与搬运期间不能开火。许岚、孟齐和周延是独立人物；这仍是占位动作与字幕，没有正式配音和接触动画。

S04 要先在街角看向军车旁的港务人员并报告，再推进检查口、检修下层、3 米高的栈道、生活院后门和转运位。两道门的事实更新表现、碰撞和导航；角色实际走台阶。九名技工保留原 ID，两名初始在军车旁的人员通过外环进入后区；通知撤离后九人走到安全区，孟齐到接应位置后才可交接。接应期间被近敌压住的人员会停步，目标标记优先指向他们，玩家需要巡查侧翼。

E01／E02／E03 使用有限入场预算 18／20／18；预算是上限，不是必须刷完的击杀配额。活跃上限 8、同时瞄准上限 2。阶段由观察、设备、射界、人在场和实际交接推进，不用倒计时宣称救人成功。完整占领区的敌方协作、押运表演与战斗节奏仍待完善。

连续流程只接 S03→S04。S04 结束明确显示“本段接应完成”，不会把旧 V2 自动当成正式 S05，也不会宣称战役已经通关。

新路径回放只生成公开 Intent，不直接改写位置、血量、演员、事实或任务阶段。S04 检查闭门实体阻挡、开门同帧射线通行、实际穿门、无跳跃上下台阶、九个稳定人物逐帧连续移动、实际到达和交接；同时检查敌人数／瞄准者／预算上限。机器人可读取世界状态、精确瞄准并选择巡查路线，因此证明的是仿真链路，不是真人难度或完整浏览器通关。

修复过的实测问题：Rapier 的门设置为禁用后，旧查询条目要到下一固定步才移除。开门当帧现在以 JS 侧 disabled handle 集合过滤，查询回调不再重新进入已借用的 WASM ColliderSet。保留即时射线与后续实际穿越断言。新存档检查还拒绝敌人编号超出 `mission.spawned` 的损坏记录，避免恢复后生成重复 ID。阶段切换的强制入场也统一检查人数和预算；专门反例曾测到 S04 达到 12 人、北闸达到 8 人，修复后分别保持 8／6 上限，延后新组入场而不删除旧敌人。

导航现支持按场地给定边界，开放队列使用二叉堆；开门后重建可通行区域并清掉过期路径。当前仍为平面导航，工人使用地面路线；玩家通过实际胶囊控制器走楼梯，不把二维导航冒充三维导航网格。

## 存储与交付边界

SaveStore 使用本机 storage、版本包装、严格结构校验和上一份有效备份。读取损坏主记录可回退并显示原因；覆盖前保存损坏原文；不覆盖未来版本；写入失败保留旧主记录。连续章节槽与独立场景槽分离。恢复重建人物、物理和门状态，保留随机状态、弹药与任务，清除旧弹丸。浏览器与 Electron、不同来源／端口之间不自动共享；当前没有导入导出、云同步或已发布旧版本迁移。

`npm run package:win` 完成类型检查、生产构建和 x64 便携目录生成。生产 JS 约 5.03 MB、gzip 约 1.86 MB，仍包含 Rapier compat WASM；尚未拆包优化。`node scripts/inspect-package.mjs` 核对应用包只含 `LICENSES`、`desktop`、`dist` 和最小 package，打包内容与当前源码／dist 一致，EXE 是 x86-64 PE。散列与当前测试数见 [build-manifest.json](chapter-build-manifest.json)。这项检查不启动 Windows 游戏。

当前便携候选位于 `release/ReturnToGanymede-win32-x64/`，新压缩文件名为 `ReturnToGanymede-chapter-preview-win-x64.zip`。旧 `ReturnToGanymede-whitebox-win-x64.zip` 保留为首轮候选。EXE 必须连同整个文件夹转移；尚未提供签名安装程序。
