## 界面与诊断顺序

1. 默认“近距无雾”：原工厂，原材质，米制机体，50°相机；确认主体、座舱、双翼和尾部是否实际渲染。
2. “近距灰天”：保持相机，使用 S12 灰天和 `.004` 指数雾，比较配色。
3. “S12 近点 .004 雾”：原 `EpilogueAirCover`，默认固定路径时间 6 s；相机 `[-4.1,1.7,-1.05]`、正北、上仰 `80*2.6/720` 弧度、FOV 75°。本页没有房屋、围墙或完整关卡，不替代实景验收。
4. “S12 同点无雾”：仅移除场景雾。
5. “法线诊断”与“白色无光照诊断”：只在检视页切换 scene.overrideMaterial，不改变源资产。若这些能显示轮廓而原材质不易辨识，进一步检查光照/颜色/雾，而非用提交的 Draw 数证明可见。
6. 路径时间可用滑杆固定或勾选播放；“悬停放轮”只改变近距检视机的真实源机构。

公开面板显示相机、模式、时间、Draw/Tri、每架根位置/NDC/可见网格及错误数。没有访问游戏的隐藏全局状态。
