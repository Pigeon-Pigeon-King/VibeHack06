# 重返木卫三 · 路演演示

双击 index.html 打开。方向键／空格翻页，F 全屏，N 打开同步演讲者备注；触屏可左右滑动。备注含两分钟讲稿和计时器。最后一页点击播放45秒影片。

8页分别呈现作品、木卫三、两条复仇线、人物选择、玩家行动、Codex制作流程、创作者理念和影片。每页只保留一个标题与最多一行说明，完整讲稿在备注中。

本次已填入两张真实游戏截图：S01九岁闻川眼中的父亲与主厅居民，S05周延视角的北闸。S05也用于玩法页局部和收束意象。未拍到的周延人物、护送、协作搬运及接收通路仍保留原有线稿占位，不将它们标成实机。截图保留原始HUD；部分页面仅通过CSS裁切显示。

影片 assets/trailer-45s.mp4 为1920×1080、30 fps、45秒故事剪辑版：开头3.6秒采用现有S05原片，其余为明确标注的S01/S05实机截图、剪辑推拉与最后4秒片名。包含已完成的专用配乐、闻川旁白及六句中文字幕。按用户“不要再录制，优先交付”的决定停止采集，没有新增游戏录制；本版没有连续交火镜头或游戏同期音效。截图推拉是剪辑效果，不是游戏镜头运动。

assets/title.png 是ImageGen生成的2172×724 RGBA透明片名，游戏与影片可复用。assets/trailer-audio-preview.mp3 为配乐和旁白试听，位于备注窗口。既有占位预剪文件仅保留为历史记录，不在演示中播放。

备注中的试玩与源码入口：[游戏](https://pigeon-pigeon-king.github.io/VibeHack06/)、[Clide备用入口](https://7ja2szw7s.clide.app/)、[公开源码](https://github.com/Pigeon-Pigeon-King/VibeHack06)。这些外部链接需要联网；演示与影片可完全离线打开。

请复制整个目录，保留CSS、JS与assets；也可直接解压交付ZIP。具体媒体来源和剪辑范围见项目 artifacts/trailer-45s/v2/delivery-cut/manifest.json。浏览器验收记录另存 artifacts/submission/browser-qa/。
