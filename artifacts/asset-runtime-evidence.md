## 浏览器实际操作

使用现有本地候选 `http://127.0.0.1:5191/`。页面操作一度超时；恢复同一浏览器连接并等重负载检查结束后继续，未用其它浏览器技术绕过。

1. 北闸实际显示导入的 AK-47 与材质。初看金属部分过暗，加入程序化间接反射后复查；`asset-runtime-browser/ak47-ads-desktop.png` 是1366×768的实际瞄准画面。方块手臂仍是代理，不是正式角色动画。
2. 在844×390开启触屏操作，以鼠标模拟单个接触，实际按住开火、切换瞄准、换弹、摇杆移动与拖动观察。固定尺寸重开后：25/150开火至20/150，换弹显示“装填中”，结束为25/145；随后移动／观察仍为25/145。松手后开火按钮没有 `is-held` 样式。
3. 拖动观察后，屏幕边缘出现“身后13m”的目标指示。实际前进到称重台，用触屏“接通撤离线”，任务进入“称重台撤离”，显示具名字幕；见 `touch-look-edge-marker.png` 与 `touch-terminal-and-subtitle.png`。
4. 未掩护战斗期间实际出现“你倒下了”；用重试按钮恢复到新的“02·称重台撤离”检查点，任务和弹药恢复，随后用Escape暂停。没有据此声称完整北闸通关。
5. 390×844实际查看恢复后的HUD、字幕和触控区，原截图见 `touch-portrait-retry.png`。观察到竖屏持枪机匣偏出画面，之后按宽高比收回腰射横向偏移，保留模型等比尺寸和ADS校准；真实几何投影测试通过。随后实际进入S05复查，机匣留在画面内、HUD和具名字幕可读，见 `ak47-portrait-final.png`；之后暂停并恢复默认视口。
6. S12通过公开开发检查点入口导入 `tests/fixtures/finale/epilogue-7.json`；它是以前公开输入自然回放记录，摘要和来源见对应source文件。站在门口时实际达到人员／物资4/4并完成；重新恢复、走出门后仍停留于接收任务。只证明检查点局部恢复，不能作为全章人工首通。
