## S01／S02 如何接续

**S01 是九岁陆闻川的有限视点。** 父子日常、清理通道和门口交接可以保留；撤离与父亲冲出后，镜头和可见空间留在儿童所在的通道。回望、停留、跳过或读档都不能恢复他对 T05—T08 的目击。不能以旁白、字幕、目标文字或完成页向九岁的闻川补发主厅后半段知识。此时他知道自己被带离、父亲没有跟上，不等于已经目击父亲死亡或知道凶手。

**S02 回到同一事件前段的二十三岁周延视点。** 从防守、开门及护送阶段补完同一场失守，再继续到儿童看不见的 T05—T08。S01 的结束与 S02 的开始是叙事视点切换，不是故事时间顺接后又发生第二次防守、撤离或轰炸；门、梯道、居民路线及父亲冲出的位置应相互吻合。转场应让玩家知道回到了同一时刻附近的另一位置。

玩家已经体验另一视点，不代表当前角色获得全部信息。内部世界事实、当前角色已知信息与玩家已看过的演出要分清；同一事实也不能让字幕、道具和完成页提前泄露后续事件。

## 保留事实与未作出的裁定

- **陆建平最终死于这场灾难的既定剧情保留。** 本轮改变儿童的目击范围，不改写父亲存活；也未确定直接致命因素、具体射手或其与轰炸的精确先后。成年闻川对父亲死亡的认知不应倒填为儿童现场看见。旧后续章节也没有确认具体杀父者，不能升级为邵原亲手杀父。
- **赵启明的授权、被俘和被邵原处决保留。** 新裁决补足班长来不及拿起武器便被控制，并限定其与群众遭袭、周延受压近乎同时。既有对白如继续使用，应服务于暴行正在发生时的怒吼，不能恢复旧的先求情后屠杀顺序。
- **周延后来获救、接受医护帮助并存活到成年保留。** 这不属于他在 S02 昏迷前可知的结果。后续章节可通过已经知道的经历补足，不能增加昏迷后的全知救援镜头来延长 S02。
- **本轮只确认避难所遭轰炸。** 没有确认轰炸方、弹种、平台或动机，制作文本、特效命名和音频说明均不据此加定论。

保留事实来源：[世界与故事](handoff/current/02_WORLD_AND_STORY.md)、[人物与成长](handoff/current/03_CHARACTERS_AND_ARCS.md)、[小说原文第三／四章](handoff/current/references/novel_original.md)。上述来源中与本次视点及顺序冲突的段落，由本文件覆盖。

## 实现与验收边界

本轮正在修改序章逻辑、共享时间参数及其表现、存档和回放；此文档只确认裁决，未宣称这些接线已经完成。约定的共享接口位于 `src/content/opening-timeline.ts`：`OPENING_TIMELINE.childhood`／`.mainhall` 与 `openingHallTime(phaseTime, facts)`、`openingCrowdHitTime(index, count)`；具体秒数由实现统一提供，本文不复制第二套计时。正常播放、允许的跳过和检查点恢复应到达同一剧情终态，并保留已经撤离的居民。旧档兼容不能把旧的父亲死亡镜头、先求情后屠杀或直接获救描述重新带回。

需分别检查：时间顺序与事实回归；真实浏览器中儿童视线、周延受困、近乎同时的入侵／受控与昏迷；普通玩家对同一历史的理解；正式角色动作及声音；目标 Windows 实机。本轮文档核查没有完成上述运行验收，旧自动回放与代理画面也不等于新时间线、正式动画、真人或 Windows 已通过。
