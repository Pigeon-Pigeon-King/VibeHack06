1. **文档中的工具状态滞后。** 原 `docs/ASSET_PIPELINE.md`、`docs/COMPETITION_COMPLIANCE.md` 中尚未提交 Tripo/Hyper3D 的句子属于早期状态。生产目录已有真实 3D 任务与音频生产记录；表单草稿已更新为实际使用，并保留“素材产出/运行集成/验收”的区别。由相应维护者更新公共说明，保留历史时间边界。
2. **候选与来源包会随代码变化失配。** 保留的审计记录检测到 `EpilogueAirCover.ts` 在读取期间变化；最终网页审计中，组件包 18 项里有 16 项匹配所选源码，另两项是该文件和对应测试。按各份报告的时间读取差异，不把并行工作中的产物叫作冻结版。最终冻结后重新生成组件源码包并构建，再对其清单与 dist 审计；本窗口没有替主窗口重打包。
3. **旧 Windows ZIP 不含当前候选。** 其结构/CRC/PE/ASAR 的可读性不代表最新资源已经入包。将旧包与候选网页逐文件比较会失败，这是应有的版本差异；需要从同一冻结输入生成新包。Windows 启动、输入、声音、存档与性能依然需要目标设备，当前 `NOT_RUN`。
4. **准备好的音频尚未成为运行声音。** 本轮明确清单中的 224 个声音文件可进行摘要和头部审核；读取的运行源码仍使用临时 Web Audio 合成。音频发布副本中的本机路径以及音乐许可/输出使用依据需在来源记录中补齐，不能仅凭文件可解码判为已获完整发行放行。
5. **宣传片部分镜头仍缺具体运行能力。** 角色/道具接触、第三人称拍摄锚点、生前周延看木星、闻川扶门背影与轨道空降舱/登陆艇均按执行稿逐项补齐。F-35B 护航不自动补足最后一项。S02 时序已随反馈进入新主线，仍需在最终人物、声音和新时序下实拍。
6. **演示入口存在开发/生产差异。** 当前 S10 章节按钮与检查点文件入口受 DEV 条件限制。路演可按本地开发备演卡明示使用；正式网页/EXE 的快速演示入口需要主窗口明确安排，或提前正常形成对应连续存档。不要向玩家承诺现有发布版已经具备导入/跳关。
