# 《重返木卫三》宣讲与预告片制作规划 v2

日期：2026-10-31。本文件保留 v2 制作规划。用户随后授权进入执行：已完成 [HTML 演示](HTML_PRESENTATION.md) 与透明标题，音频制作交给已有声音窗口；实机图片和45秒视频继续预留占位。实际状态见 HTML 交付记录。更新后的 [口播稿](SPEECH_2MIN.md) 以 [用户修订原文](SPEECH_USER_REVISION.md) 为依据。报名草稿未被当作已提交回执。

本轮用户连续修订优先：木卫三是地球联合政府的领土，由外环资产集团长期占领；居民在十年的压抑生活中迫切盼望回归。公开表达含蓄，不直接列举制度名词。旧资料中“集团仅提供外部支持”的表述不用于本版故事简介。

## 1. 这次展示要留下什么

核心理念采用用户原句：**“AI发展的时代，人是讲一个好故事的核心。”**

这句话在宣讲开头提出，最后以创作者的具体责任回应：决定人物为何改变、哪些代价必须留下、玩家要亲手完成什么。影片用两个具体的人和他们的选择，让观众感受到这句话。

观众离场时应记住三件事：

1. 木卫三等待回归已有十年，两位主角的伤痛来自同一段占领历史。
2. 闻川从追索旧仇走向兑现承诺，周延从独自偿债走向接受保护；这些选择关系到仍活着的人。
3. 人确定故事与体验，Codex 协调制作，专门工具生产资产，最终回到游戏里核对声画、行为与叙事。

## 2. 剧情的简练与升华

### 一句话

在被占领十年的木卫三，两个被旧仇牵引的人，在追击与守护之间作出选择；他们尚未平复的伤痛，与一整片土地盼望回归的心情交织在一起。

### 可用于介绍页的短梗概

木卫三是地球联合政府的领土，却已被外环资产集团占领十年。人们渐渐习惯了沉默，却始终盼着回归。闻川追索失去父亲的旧仇，周延背负没能保护好群众的心理负担。随着轨道运力重建，援军即将抵达。为了保护更多人，两人放下追杀的私情，选择兑现承诺、接受同伴保护。

### 两条人物线如何交织

| 层次 | 起点 | 真正的变化 | 与大背景的联系 |
| --- | --- | --- | --- |
| 闻川 | 失去父亲，追索当年暴行的责任人 | 完整知情、追击仍可行时，兑现护送承诺；仇恨尚在，选择有所改变 | 从自己的失去，看见身边的人也在等待故土回归与正常生活 |
| 周延 | 亲眼见班长被杀，既想复仇，也背负未能保护好群众的心理负担 | 学会共享消息、交出阵位、接受同伴保护，并愿意继续生活 | 回归所需的共同承担，开始改变他凡事独撑的习惯 |
| 木卫三居民 | 十年占领使日常生活与人与人的信任蒙上阴影 | 始终保留回归地球联合政府的愿望；援军到来使希望逐渐成为具体行动 | 港口接应是回归进程中的一步；更大的背景是居民终于有望重新决定自己的生活 |

两条复仇线具有不同的心理方向：闻川向外追问责任，周延不断向自己追债。他们的旧恨没有被一句道理抹平。故事让他们在共同生活的土地上，重新判断应该把力量用在哪里。

创作提炼句：**“旧恨把他们带回战场，对活着的人的承诺，让他们重新决定为何而战。”** 这句可用于创作说明；影片不必再叠加一条口号。

### 内部剧情底线（含结局，不用于舞台／影片）

- 闻川在父亲死亡及后续主厅事件前已离开可目击范围；不补造他亲见杀父者或班长处决的记忆。
- 周延曾扣下消息，导致冲突，之后才承认问题并完整共享；不把隐瞒改写成始终正确的保护。
- S08 追击仍可组织，闻川是在清楚代价时履行承诺；不写成追不上后的自我安慰或宽恕邵原。
- S09 周延已经接受换班与保护、打算继续生活；S10 负伤后主动求援。其成长先于死亡，不能包装为主动赴死或以死偿债。
- S11 周延救治失败，孟齐存活；S12 闻川接受帮助，继续接收人员。邵原逃离，援军开始进场，木卫三尚未全面光复。

## 3. 120 秒宣讲＋45 秒影片

主结构共 165 秒，三分钟场次保留 15 秒用于切换和现场停顿。本版替代旧稿的“20 秒开场＋45 秒影片＋95 秒现场玩法＋20 秒收束”。现场操作可作为另行问答／试玩内容，不挤入这 165 秒。

| 时间 | 职责 | 材料 |
| --- | --- | --- |
| 0—34 秒 | 核心理念、木卫三处境与回归愿望 | [两分钟讲稿](SPEECH_2MIN.md)前两段 |
| 34—80 秒 | 两条人物线、选择如何进入玩法 | 讲稿第三、四段 |
| 80—106 秒 | 简述 Codex 协调的制作流程 | 讲稿技术段＋单张流程图 |
| 106—120 秒 | 回到人的判断，引出影片 | 讲稿收束 |
| 120—165 秒 | 实机预告片 | [45 秒剪辑稿](../../artifacts/trailer-45s/v2/EDIT_PLAN.md) |

所有台上时间为编排目标；尚未真人试读或播放排练。影片的 45 秒可以在剪辑中精确控制，宣讲则靠实际试读调整停顿与句长。

## 4. 技术内容讲到什么程度

公开技术图采用以下五步，明确谁在作决定、工具怎样接力：

**人的主题与人物判断 → Codex 拆解任务与协调制作 → 专项资产与内容 → 游戏整合 → 场景检查与修改。**

| 工作支线 | 说明 | 人必须检查的内容 |
| --- | --- | --- |
| 剧情文本 | 从已经确定的人物动机和关卡节拍，展开对白、字幕与场景文字；Codex 协助填充、检查和对齐 | 人物所知是否正确、话是否像本人、冲突是否有因果、有没有提前透露信息 |
| 3D 资产 | 先审 ImageGen 概念图，再由 Tripo／Hyper3D 承接模型生产，接入绑定／动画与运行流程 | 身份与比例、动作接触、碰撞和关卡用途；模型输出不自动等于游戏里可用 |
| 音乐、音效、配音 | 音乐组织情绪与节奏；效果音响应动作；配音保持角色声线与表演 | 在场景里听是否抢对白、动作是否对齐、情绪是否适合；转写检查不能代替听审 |
| 代码与整合 | Codex 协调任务、弹丸、同伴、交互与检查点等实现，组织检查和问题修订 | 真实玩家输入、可见行为、失败恢复，以及剧情和玩法是否表达同一件事 |
| 制作方法 | 借鉴 Paean 由清楚的设计、可玩核心到资产整合与验收的流程 | 每一步留下可以查看、可以运行的结果，发现问题再回到对应步骤 |

舞台只读一小段；模型型号、生产任务 ID 与骨架数留在资料页。Paean 是这里的方法来源，当前运行工程仍按本项目的 Three.js 桌面 FPS 与网页交付约定，不额外声明 SDK 接入或平台发布。

本轮读到的整合说明已记录正式人物、部分生成场景资产及战役配音、音乐、音效进入主线。旧报名材料里的“声音尚未集成”等描述属于旧读取时点，不能直接用于新的展示页。全程实机、正式动作效果和设备验收仍须按冻结版记录核对。本方案不会把已生成、已整合和已验收混成一个状态。

## 5. 45 秒影片的整体方向

影片的情绪顺序：**等待 → 旧伤 → 重返战场 → 看见追击机会 → 兑现承诺 → 把通路留给更多人。**

以成年闻川的声线作作品外旁白。主角不用在游戏世界里解释 AI 创作理念。新的旁白独立于战役对白，先审稿，再按已选声线制作与试听。

每个镜头最终取自游戏内实际运行，包括其中的演出和真人操作。镜头可以按本方案安排，所需动作、人物、场景要先在游戏内做到并检查；概念图不能充作实机。连续射击片段保留玩法可读性，搬运与守门展示角色选择的后果。

声音采用独立的 45 秒原创配乐，保留游戏内开火、命中、爆炸、脚步和环境音。录制时关闭原游戏音乐，新旁白占用独立轨道；原游戏对白按镜头选择避免重叠。音乐以《赛博朋克 2077》作为工业电子与战斗推进的高层听感参考，具体旋律、动机与录音原创。

片尾 41—45 秒完整展示统一的透明标题。标题图片未来同时用于游戏菜单、影片和 HTML 演示。详细镜头、音乐节拍、声线依据和图像需求均在 [新版剪辑稿](../../artifacts/trailer-45s/v2/EDIT_PLAN.md)。

## 6. 后续 HTML 演示结构（本轮不实现）

采用五页讲述内容，加一页本地视频。每页一个清晰重点，讲稿放在演讲者备注中。

| 页面 | 显示内容 | 对应讲述 |
| --- | --- | --- |
| 1 | 《重返木卫三》＋“AI发展的时代，人是讲一个好故事的核心” | 0—14 秒 |
| 2 | 港区实机画面＋“十年占领，始终盼着回归” | 14—34 秒 |
| 3 | 两位主角、各自的转变；掩护／救援／守门三个动作 | 34—80 秒；按讲述逐步显现，避免一屏塞满 |
| 4 | 人的判断 → Codex 协调 → 文本／模型／声音／代码 → 场景检查 | 80—106 秒 |
| 5 | 一句收束：“人物为何改变，仍要由人判断。” | 106—120 秒；保留人工播放影片的入口 |
| 6 | 45 秒本地视频，全屏；结尾停留标题 | 120—165 秒 |

后续实现以键盘翻页、人工控制为主；可选演讲者计时，不强制自动切页。本地打包视频、字体与图像，不依赖现场网络；通过明确的点击／按键启动音视频。标题保持同一源资产和宽高比。开发中状态放在可读的简短注记中，不用小字隐藏。

## 7. 后续制作顺序与交付

| 顺序 | 任务 | 可审阅结果 |
| --- | --- | --- |
| 1 | 校准讲稿、镜头和旁白，实读两分钟 | 录音计时与修改后的文字；当前只有文稿 |
| 2 | 确认拍摄构建、补齐必需画面和录音预设 | 同一构建中的取景样片；原 BGM 静音，实机音效可听 |
| 3 | 沿用闻川已选声线制作旁白；制作原创配乐；ImageGen 透明标题 | 旁白干声、45 秒音乐、RGBA 标题；各自先检查 |
| 4 | 实机录制与剪辑 | 原片、镜头来源表、独立音轨、可修改工程；音乐为剪辑节拍参考 |
| 5 | 混音与输出 | 45.000 秒成片、无旁白备用版本、字幕、海报帧；实际播放检查 |
| 6 | 做 HTML 演示并排练 | 本地可打开的演示包；120＋45 秒完整排练，保持 15 秒余量 |

人物／地图与运行实现由对应窗口负责，声音由声音窗口负责；本窗口提供镜头和音频需求、组织剪辑与宣讲材料。该分工现已按用户授权推进 HTML、标题和声音；实机录制、游戏音频入口与影片制作仍未在本窗口执行。
