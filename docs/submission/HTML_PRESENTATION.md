# 《重返木卫三》HTML 演示

入口：[index.html](../../artifacts/submission/presentation/index.html)。也可使用 [完整离线演示包](../../artifacts/submission/ganymede-presentation.zip)，解压后打开其中的 `index.html`。全部资源在演示目录内，不需要启动游戏或连接网络。

## 使用

- **左右方向键／空格**：翻页；Home／End：第一页／视频页。触屏可左右滑动。
- **F**：全屏。浏览器不支持接口时，使用浏览器自带全屏菜单。
- **N**：打开独立演讲者备注窗口。展示窗口与备注窗口相互同步页码；备注窗口有两分钟计时、完整口播与素材工具。浏览器阻止弹窗时，本页显示备注作为后备。
- 鼠标移动或点击时显示底部图标控制栏，稍后自动隐藏；键盘聚焦时保留可见。
- 计时需手动开始，翻页由演讲者控制；没有强制自动切页或自动播放声音。

每张展示页只有一个标题与一行说明。窄屏使用同义短说明保持单行；完整文字保存在备注和 [口播稿](SPEECH_2MIN.md)。

## 后续替换素材

编辑 [media-config.js](../../artifacts/submission/presentation/media-config.js) 中相对 `index.html` 的文件路径即可；`null` 保留占位，没有对缺失素材的网络请求。

- `images.world`：港区；`wen / zhou`：双主角；`promise`：护送与接应；`cover / carry / door`：三幅玩法图；`ending`：收束画面。
- `trailer`：45 秒本地视频，建议路径 `assets/trailer-45s.mp4`。
- `trailerCaptions`：可选 WebVTT 字幕。
- `audioPreview`：音乐＋旁白的试听文件，只在备注窗口提供播放器。
- 备注窗口还可临时选择本地视频，不上传文件；关闭页面后该临时选择不保留。实际视频载入后才显示原生播放控件，不会用占位图伪造45秒成片。

标题母版：[ganymede-title-v1.png](../../assets/source/branding/ganymede-title-v1.png)。演示目录中有逐字节相同的副本；已核对真实 Alpha 通道。来源和提示词见 [标题资产说明](../../assets/source/branding/TITLE_ASSET.md)。本轮不修改游戏菜单，主窗口可按正常资产接入流程复用母版。

## 音频首版

声音窗口已产出45秒音乐、六句旁白干声、45秒旁白轨、字幕和音乐＋旁白试听混音。演示包已包含 [MP3试听](../../artifacts/submission/presentation/assets/trailer-audio-preview.mp3)，可在备注窗口的“素材与试听”中播放；它不含实机枪声、爆炸或环境音。音乐、旁白及试听混音的 WAV 母带均读取核对为 48 kHz／2,160,000 采样帧／45.000 秒。配音表演与最终混音仍待用户听审，未据自动转写或波形检查声称听审通过。

完整声音在项目 `design/audio/trailer45-v2/delivery/`，本窗口只复制试听文件，不改原件。来源与副本摘要见 [音频交接记录](../../artifacts/submission/audio-production-handoff.json)。
