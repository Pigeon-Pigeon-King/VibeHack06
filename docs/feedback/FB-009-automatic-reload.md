# FB-009 · 打空弹匣自动换弹

日期：2026-10-31。来源：用户要求“记得加入打空子弹自动换弹功能”。

弹匣打空且仍有备弹时，最后一发的射击周期结束后自动启动原有换弹流程，耗时仍为 2.1 秒。R 可提前换弹；备弹不足时只装入剩余数量，备弹耗尽时不重复触发空换弹。

自动启动服从战斗控制权：工作、搬运与固定剧情不启动；暂停不推进模拟；已经进行中的换弹从检查点恢复剩余时间，不重置或再次播放起始事件。不新增存档字段。HUD 使用现有换弹进度，空枪不再要求玩家必须按 R。

实现：[Simulation.ts](../../src/mission/Simulation.ts)、[GameUI.ts](../../src/ui/GameUI.ts)。四项定向机制测试位于 [automatic-reload.test.ts](../../tests/automatic-reload.test.ts)，涵盖最后一发、持续时间、备弹、受限控制权、手动换弹与恢复；这些构造场景不作为人工完整通关证据。最终结果见 [本轮验证](../../artifacts/feedback/FB-007/EVIDENCE.md)。
