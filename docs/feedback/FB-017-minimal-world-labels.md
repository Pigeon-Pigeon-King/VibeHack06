# FB-017 · 移除悬空区域说明，保留实体导向牌

日期：2026-10-31。用户反馈地图上悬在地块上方、说明该处功能的文字没有必要。状态：已清查正式 S01—S12 与三个旧验证场景，移除悬空功能说明和任务解说，专项几何检查通过。修改基于反馈树 `fa9f2d5`；浏览器 CUA 仍被 Work 设置禁用，本记录不包含视觉实测、手机或 Windows 验收。

原 `PortKit.label()` 给每次调用创建独立 `CanvasTexture` 和 `PlaneGeometry`，没有要求附近存在实际牌板。部分文字被放在设备、桌面、通道或地块上方；有些旁边只有一根或两根立柱，不能形成完整实体牌面。另有少量真实门楣牌的高度超出了门楣，形成部分悬空。

本轮删除无用调用，把保留入口明确改名为 `PortKit.sign()`，仅用于现有门楣、墙面或实体牌板上的短导向文字。没有为旧文字新建支架。所有非文字网格、实例变换、碰撞、门、路线和剧情逻辑保持原样；医疗桌和尾声桌面的辅助函数只去掉不再使用的文字参数。右上数据面板及人物身份提示由其他反馈任务处理。

## 保留牌的几何依据

[world-signage.test.ts](../../tests/world-signage.test.ts) 调用真实 `buildEnvironment()`，只替换 Canvas 的绘图 API，使 Node 能创建文字材质。它没有替换场景构建、Three 网格、实例变换或射线查询。每张保留文字面在中心和距边缘 1% 的四角向后发射射线，要求 10 cm 内命中同一个可见实体网格／实例；立柱或只有边缘框架不能满足这一检查。门打开后的状态也执行该检查。

## 验证结果

- 当前源码：**16 项文字检查、6 项地面检查、2 项可替换视觉槽检查，24/24 通过**。文字检查包括全部 15 个场景、短文本上限、任务解说词回归和关键实体门牌仍存在。
- 修改前对照：通过只读 Vitest `load` 插件从 Git `fa9f2d5` 将 12 个相关源模块载入内存；**16/16 新文字检查失败**，包括悬空无背板、文字冗长和数量超限。没有回退工作树文件。
- 修改前后分别构建 15 个场景，逐场比较 `solids` 序列化摘要，以及剔除 `sign-*` 后的节点名称／类型／可见性／阴影标志／世界矩阵、网格顶点／索引与实例矩阵摘要：**15/15 场景均相同**。此对照只用于本次定向审查，没有加入大范围固定快照。
- `npm run typecheck` 和 `git diff --check` 通过。没有全战役回放，也没有写入用户运行状态。
