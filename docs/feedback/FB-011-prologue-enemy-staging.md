# FB-011 · 序章敌军门外集结与防守目标

日期：2026-10-31。状态：逻辑修复与共享 Simulation 接线已实现，36 项序章专项及 1 项公开输入防守／撤离回归通过；浏览器视觉与真人操作尚未验收。

用户实测：序章敌人像在大厅里逛街；敌军应先在大厅门外准备突入，可操作防守阶段应对玩家威胁作出明确反应。

本项遵守 [序章统一时间线](../PROLOGUE_TIMELINE.md) 和 [FB-007](FB-007-prologue-order.md)。S01 九岁闻川保持非战斗视点；S02 的防守、真实撤离、守军伤亡、孩子离开、轰炸坍塌、敌军突入／群众遭袭／周延受压／班长受控、怒吼击杀、昏迷的因果不变。已撤离者不会被改回受害者。

## 已确认原因

- `Opening.ts` 开门后的首批敌军直接以 `H.enemyPosts` 生成，这批点位全部在大厅内部；第二批与后续增援还带有前往大厅内阵位的任务导航目标。
- `Simulation` 会优先执行人物任务路线。敌人虽只把玩家放进常规战斗目标表，仍可能沿既定室内路线移动，形成忽视眼前威胁、四处行走的观感。
- 失守演出从 phase 4 开始就创建两名突入兵和邵原。旧起点在大厅内，早于 `history-enemy-breach`；渲染可见性虽受事实控制，真实人物与物理体仍提前存在于厅内。
- 原防线安全检测半径为 20／18 米。若只把敌人移到门外而不调整射界检测，仍在向防线施压的敌人会被排除，居民可能立即被放行。

## 修复范围

实现位于 `src/mission/Opening.ts`，调用接口由 `src/mission/Simulation.ts` 接入。

S02 初态四名战斗敌人位于东侧公共入口和北侧入口外。开检修门的工作阶段不允许战斗 AI 开火；进入防守后，他们以玩家为唯一常规战斗目标，使用真实遮挡、弹丸和碰撞。旧的室内导航目标已删除，增援选取未被占据的门外阵位。战术活动范围限制在阵位周围 0.9 米，侧移仍由战术系统与 Rapier 完成，没有逐帧传送回门外。

防线的安全检测扩为 52 米并继续检查实际遮挡；居民身边和撤离通路的近处安全检测仍为原规则。门外站位既可从防守点还击，也不会仅因距离增加就自动视作火线安全。S01 不新增战斗敌人，不对儿童启用仇恨或伤害路径；已有守军及父亲的剧情掩护弹道改为朝向门外，仍保持零伤害与原事实时刻。

后半段演出的三名敌军从公共入口外等待，在共享时间线的突入时刻才向厅内移动。第一名敌兵冲入约 6.7 米后举枪控制赵启明，阻止其拾枪；这一安排保留突入后约 1.1 秒受控的批准时序，同时避免从门外以每秒二十多米穿过全厅。群众射击继续由独立的剧情敌兵执行；不能把这一暴行改成对无敌玩家的攻击。其余演出时间、群众规模、角色视点与配音时长均未修改。

`restoreOpeningEnemies` 在保存人物物理体建立后、首个 AI 步前迁移旧档。`history-enemy-staging-v1` 使迁移只执行一次：旧档仍在厅内的存活战斗兵移至门外，过期室内任务路线清空；死亡敌人、健康值、冷却和居民撤离结果保留。新版存档保留准确的战术中间态。已记录突入的后段档案不被倒退到门外。

## 证据与边界

新增 `tests/prologue-enemy-staging.test.ts` 使用实际大厅 `buildEnvironment`、真实 `Simulation`、Rapier 与 `SaveStore`，检查初态、门口射界、工作／战斗控制权、玩家目标、局部移动、真实墙体遮挡、旧档首帧迁移、突入前后及居民保护。后半段时序使用明确标注的已撤离构造边界，不能据此声称完整操作流程通过。

- `opening-timeline`、`opening-autonomy`、`opening-presentation` 原有 28 项与新增 `prologue-enemy-staging` 8 项合计 36 项全部通过，没有跳过；原有测试未修改。
- 新增专项的首轮共享接线前基线为 4 项通过、3 项失败，准确指向 0.9 米活动范围和两种旧档首帧迁移缺少接入。反馈工作树完成构造恢复与战术范围的最小接线后，这些失败以及补充的旧空场入口迁移用例均通过；最终与其它窗口的共享文件改动一起整合。
- 门内控制班长的短冲入、碰撞净空与枪口射界专项通过，`npm run typecheck` 与 `git diff --check` 通过。
- 单独执行 `opening-paths` 的 `physically evacuates six residents...` 用例通过：正常播放和允许的跳过两条公开输入回放都经过 phase 0→1→2→3→4→5。六名任务居民各自真实移动约 34.62—47.66 米、下楼并进入隔断后安全区；两条路径的剧情终态与人物终态一致，未出现战斗失败。该用例只发送公开 Intent，不改写人物位置、生命、弹药、阶段或事实。
- 正常回放的模拟时长为 67.47 秒，跳过为 35.87 秒，均发送 138 帧射击输入并形成实际命中；这不是实机首通时长或真人体验结论。回放程序用时 4.08 秒；其余四个既有 `opening-paths` 用例未在这次定向命令中重复执行。
- 完整构建由整合窗口核验，不在此借用其他版本的结果。
