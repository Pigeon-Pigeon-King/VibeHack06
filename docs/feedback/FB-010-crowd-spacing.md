# FB-010 · 群众站位与队列自然化

日期：2026-10-31。来源：用户要求“人物排列不要过于整齐，其他涉及群众的关卡也是的”。

序章群众按疏密不同的小群布置，分开初始朝向、撤离延迟及短逃反应；六名任务居民与背景群众身份分开，已救人数不因演出撤销。S04 港务员、S05 维修工、S07 家属与维修员、S08 陪护及随行同伴、S09 收尾设备员、S12 接收人员的等候点或到站位置采用独立的不规则落点。窄门、桥面、铺板梯、病床与交接锚点仍服从实际空间与任务要求。

另修正序章／北闸分批下发路线时复用同一组落点的问题。群众不再同向、同步摆臂：匿名群众的初始朝向与步态相位来自稳定的身份散列，不消耗战斗随机数，也不在每帧随机改变。

新 S07／S08／S12 使用 `crowd-staging-v1` 记录本局布局。没有该事实的旧中途档保留原有目的地和到达判定；已在路上的人不瞬移，新局采用新布局。其他章节使用原到达范围和保存的路线，不改已救事实。

`tests/crowd-staging.test.ts` 的 10 项检查已通过：六个后续场地的站立净空、地面支撑和落点间距，身份姿态的重复性／恢复，以及三个旧版到达检查点的继续推进。该文件包含构造的兼容性场景，不作为正常战役通关证据。全部公开输入回放及最终画面范围见 [本轮证据](../../artifacts/feedback/FB-007/EVIDENCE.md)。

当前角色、动作、坍塌与声音仍为代理表现；自然化完成不代表正式群演、真人全战役或 Windows 性能验收完成。
