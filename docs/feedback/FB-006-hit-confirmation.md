# FB-006 · 白色命中、红色击杀与战斗 HUD

日期：2026-10-31。分类：战斗反馈与 UI 体验。状态：已实现，自动测试与浏览器工具射击验证通过；待用户试玩与 Windows 验收。

## 用户要求与范围

普通命中用白色叉、确认击杀用红色叉，让玩家及时区分结果。用户进一步要求**以后全部 UI／HUD 以《使命召唤：现代战争》系列为表现基准**，已记录于 [UI_DIRECTION.md](../../design/UI_DIRECTION.md)。本作沿用清楚的信息层级、冷灰军事界面和快速战斗反馈，保留原创图形与排版。

本轮落实命中确认与部分战斗 HUD 的冷灰、细线和弹药数字层级；菜单、字幕、道具交互与全套 UI 的后续精修仍需分别验收。未将本轮样式修改报为全套界面重制完成。

本轮在隔离分支完成并吸收主线字幕／手持道具；与战斗 AI 共用初轮证据，见 [FB-003](FB-003-combat-ai.md)。后续主线整合与完整回归见 [本轮最终记录](../../artifacts/feedback/FB-007/EVIDENCE.md)。

## 已实现行为

- 只有**玩家的真实弹丸命中敌人**才产生命中确认；造成该敌人死亡时再产生击杀确认。同伴射击、普通开火或击中友方不触发这套玩家反馈。
- [Simulation.ts](../../src/mission/Simulation.ts) 管理事件与衰减：白色 `hitFlash` 约 0.2 秒，红色 `killFlash` 约 0.33 秒。暂停时隐藏；恢复／检查点重建不残留旧击杀反馈。
- [HitConfirmation.ts](../../src/ui/HitConfirmation.ts) 将反馈映射为白色 `#f6f8fa` 或红色 `#ef5656`。重叠时红色优先，透明度取仍有效反馈的较大值；无事件时隐藏，异常输入归零。
- [GameUI.ts](../../src/ui/GameUI.ts) 与 [modern-combat.css](../../src/ui/modern-combat.css) 使用项目 CSS 绘制四段叉形并调整选定 HUD 元素。没有导入《现代战争》的截图、字体或其他美术资产。
