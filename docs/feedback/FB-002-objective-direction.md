# FB-002 · 离屏目标方向

日期：2026-10-31。分类：既定 HUD 要求的功能补齐。状态：已实现，自动检查与浏览器工具操作通过，待用户试玩。

## 现象、复现与预期

原实现只有左上目标文字／距离和场景内标记；把相机转离目标后无法在屏幕上判断转向。修改前从 0.5.0 主线 `230b8a9` 的 S03 独立入口进入，保持出生位置，向右转约 1 秒可复现，见 [修改前](../../artifacts/feedback/FB-002/before.png)。

预期：目标在相机视野外时给出沿屏幕安全边缘的方向和距离，处理身后、抬头低头、ADS 视野及窗口尺寸；暂停、菜单、失败、完成和固定演出期间隐藏，不影响操作和任务事实。

## 实际影响与并行检查

- 新增 `src/ui/ObjectiveIndicator.ts`、`objective-projection.ts` 和 `objective-indicator.css`，复用 `sim.objective.point`，只读相机和游戏状态。
- `src/main.ts` 只新增导入、成员、构造、每帧更新、释放五处接线；未修改 `GameUI.ts`、共享契约、任务、输入、存档或章节推进。
- 排查开始时备用工作树的 `main.ts`、`GameUI.ts`、`Simulation.ts` 等正在被主窗口编辑；本轮实现避开其改动位置。期间主窗口将 `12459dc`／`705e894` 合回 main，再归档至 `4fd68c5`。合入后主入口 diff 仅剩本轮五处新增，备用工作树保持其原有提交与内容。
- 实际浏览器验收基于合入后的 0.6.0，入口为本窗口独立服务 `http://127.0.0.1:5190/`；主窗口 5188 服务未改动。

## 实现

相机空间投影决定目标是否离屏。目标在身后时保留真实左右方向，正后方使用小范围方向保持，避免在左右边缘反复跳动。指示器沿安全边界避开目标文字、字幕、生命、弹药、错误条和诊断层，使用现有琥珀色与程序绘制箭头；不拦截键鼠。

文字仅为“目标／身后＋距离”。目标进入相机视野后交回原有场景标记；距离小于 1 米时收起。没有增加路径规划、隔墙透视目标或武器瞄准标记：箭头表示目标方位，仍须沿真实可通行路线走。视野内被实体遮挡的提示仍是完整导航 HUD 的后续缺口。
