# NPC 移动配速

2026-10-31 用户要求：正常 NPC 以 4–5 m/s 移动，让成人玩家步行跟不上、冲刺能够跟上，减少长距离同行的空等。

| 场景 | 目标速度 |
| --- | ---: |
| 普通成人 NPC 路线、敌我战术换位 | 4.5 m/s |
| 自动患者车、物资车及正在执行对应同行路线的人员 | 4.0 m/s |
| 成人玩家步行 / 冲刺 | 2.1 / 6.3 m/s |
| S01 儿童引导中的父亲和固定撤离演出居民 | 原配速 2.1 m/s |
| S10 双人手抬伤员 / 受伤退入遮护 | 原配速 1.5 / 1.0 m/s |
| S10 最终医疗转运 | 原配速 5.5 m/s |

这些数值是物理控制器的巡航速度。拐弯、碰撞、排队、精确停靠以及任务要求的停步仍然有效。测试同时测量真实移动帧速度和整段运输耗时，不把含停车的平均速度当成巡航速度，也不只检查常量。

普通路线和战术换位在 [Locomotion.ts](../src/actors/Locomotion.ts) 与 [Simulation.ts](../src/mission/Simulation.ts) 接线。S06 许岚、S07 分流人员、S08 同行人员、S10 转运医护和 S12 入门人员按具体阶段配速；S08 接防组返回北闸后恢复 4.5 m/s。负伤停步、工人遇威胁等待及无人扶门时暂停接收继续优先于速度配置。序章与护理演出的时钟、成人玩家速度、木卫三重力和弹丸飞行规则保持各自职责。

`walk` 仍是已有的存档字段，在物理步结束后按真实水平位移累计，过滤每帧不超过 1 mm 的静止接触抖动。被墙或车队阻挡时不再按预定速度空转；双人搬运不重复累计步态。固定序章演出继续设置自己的姿态相位。新速度不写入快照，旧档不需要版本迁移。

S08 在 [Escort.ts](../src/mission/Escort.ts) 中给陪护安排侧方通道，护卫使用外侧通道和等待位置；换车后先从病床后侧转入外弯，再过医疗桥。患者身份、换车顺序、患者与陪护目标及最终接防出口不变。旧档已经保存的路线仍按原目的地续行；新下发的车队路线使用分隔后的通道。

S10 在 [Rescue.ts](../src/mission/Rescue.ts) 与 [Physics.ts](../src/runtime/Physics.ts) 中处理已装载乘客。玩家进入床体后随床已经通过碰撞检查的下一物理步移动，避免第二个地面控制器追赶时积累延迟；加载和手抬阶段不使用乘载。离床较远的旧档先物理接近再接入，不能借此跳到终点或直接写入完成事实。

验证入口为 [npc-movement.test.ts](../tests/npc-movement.test.ts)、[escort-paths.test.ts](../tests/escort-paths.test.ts) 和 [finale-paths.test.ts](../tests/finale-paths.test.ts)。执行结果与证据边界见 [本轮记录](../artifacts/npc-pace/README.md)。自动物理回放不代表浏览器画面、真人体验或 Windows 实机验收。
