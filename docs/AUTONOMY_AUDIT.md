# 全战役自主推进审查

2026-10-31 用户裁决：不能把所有节点交给玩家按 E 推进。居民、同伴与工作人员有自己的职责，环境允许时应自行行动。此表对应 Nativue 的 `mission`、`actors`、`gates`、`staging`、`persistence`、`presentation`、`chapter`、`s01`—`s12` 与 `qa` 节点。

## 判定原则

- **世界条件触发**：门已打开、局部火线受控、路线可通、接防者实际到位、人员真正通过时，自行撤离、到岗或报告。玩家的职责是创造安全条件或与人会合。
- **亲手操作／主动决定**：操作开关、搬物资、持物交接、开始抬伤员、主动回复家人、提交完整记录、扶住通道门等保留 E。
- **空间与视线触发**：看清异常、进入谈话区域、走到探视位置可自然接话。区域需有实际用途，不能只为下一条字幕设置不可见小圈。
- **真实推进**：撤离、车辆、医护接手与接防仍由实际位置和路径判断。短暂提示或对白窗口只负责可读性，不能替代移动和安全条件。一个更新步骤最多改变一个任务阶段。
- **保存与反馈**：保留既有阶段编号、稳定人物 ID 与因果事实；读档后不重复下发已发生的撤离。不再需要 E 的地方同步移除 E 提示。

## 影响关系与验收

任务触发改变会同时影响目标提示、导航重算、NPC路径、对白时序、阶段检查点、旧存档恢复及回放驱动。此次逐项检查这些调用，未重新编号章节或用“按一次跳到完成”替代撤离。

回放改为只在亲手操作、主动决定和补弹点发送 E。S05 全程无 E；S02 只保留开门。安全前不推进、视线遮挡不误报、未到齐不完成、途中读档不重放路径，以及自然／跳过／恢复后的终态一致均作为回归范围。具体通过数量和浏览器覆盖以 [本轮证据](../artifacts/autonomy-finale-evidence.md) 为准；本文是裁决与实现索引。

自动回放证明逻辑条件；浏览器局部观察证明局部表现。完整正常速度人工首通、正式动画及 Windows 实机另行验收。
