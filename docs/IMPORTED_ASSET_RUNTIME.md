## 模型加载与生命周期

- `src/assets/ModelLibrary.ts` 按资产 ID、revision、URL 缓存，并合并并发加载。每个租约独立骨架和 AnimationMixer，共享只读几何、材质与贴图；最后租约释放后清理资源。
- `model-loading.ts` 只接受当前源的 HTTP(S) 或已配置的 `game://local/` 路径，拒绝外部依赖和跨源模型。当前仅运行嵌入式、未压缩 GLB；Draco、Meshopt、KTX2 解码器尚未配置，遇到这些扩展明确报错。
- 下载采用实际字节进度；未知总长不伪造百分比。加载失败保留占位枪，并在菜单／暂停页提供重试。单个请求取消不影响其它等待者；全部取消后终止下载，迟到的解析结果被释放。
- 绑定到场景前还要检查请求代次。GLTFLoader 解析中段不能直接中断，因此“取消返回”与“底层已经停止”不是同一个状态。
- `ImportedWeaponView` 先移除导入子树、归还租约，再释放自有代理和手臂。`EpilogueAirCover` 同样先移走两架机体，再调用工厂释放；`SceneDynamics.dispose` 在环境通用清理前执行，避免重复销毁共享资源。
- `DeferredAirCover` 只在 S12 的进场事实成立后动态加载飞机模块。等待期间缓存最新事实与仿真时间，离章后的迟到结果不创建机体；模块失败记入开发状态，当前场景不无限重试，重新进入场景可重试。前面章节的初始脚本不再静态包含完整飞机源数据。
- `IndirectLighting.ts` 使用 Three.js 的程序化 RoomEnvironment 生成128分辨率 PMREM反射场，给金属材质提供间接反射。仅生成一次，跨章节共用，退出时释放；没有外部 HDR。章节灯光和天空仍由原环境负责。

实现依据包括 [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)、安装版 Three.js `SkeletonUtils.clone`、[资源释放说明](https://threejs.org/manual/pages/how-to-dispose-of-objects.html) 与安装版 `RoomEnvironment`／`PMREMGenerator`。模型克隆不代表几何、材质、纹理也独占。

## 骨架检查记录

`scripts/audit-character-rig.mjs` 解析真实本地 GLB 的骨骼、蒙皮和动作轨道；替代 Node 图片解码，报告明确保留纹理和动画观看 `NOT_RUN`。禁止外部 URI 和需要未安装解码器的模型。

映射为 `artifacts/rig-audit-20261031/tripo-map-v1.json`。源模型的 `Hip` 同时承接 `Waist` 与额外 `Pelvis`，所以项目的 pelvis 语义映射到 `Hip`；不能按字符串名称机械匹配到侧支 `Pelvis`，否则躯干层级会被错误判断。头、胸、腹、两侧锁骨／大臂／小臂／手、大小腿／足／趾分别映射，辅助扭转骨也保留检查。

- 陆闻川：`CH-LU-mapped.json`，10,637 个蒙皮顶点，源摘要 `33579cb205c11d50c6fa6dfa42f93f022e387cbcf07b5a24c9a6be0b37961501`。
- 周延：`CH-ZHOU-mapped.json`，10,253 个蒙皮顶点，源摘要 `1ec1a772922bf269612bb9b7edf0d1453e297ad41ff0a739603bd9c3a0abd38d`。
- `adult-sharing.json` 保存精确模型对照。通过结构检查只说明基本结构具备条件；共享动作、关节中心、脚底和手部接触仍需实际检查。儿童使用独立校准，不与成人直接共用。

这些主角模型尚未替换运行中的角色代理。原件由美术窗口管理，不移动、不覆盖，也不把整个原件目录放进网页构建。
