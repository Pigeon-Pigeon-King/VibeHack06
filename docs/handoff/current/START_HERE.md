# 《重返木卫三》· Mac 开发交接包
版本：2026-10-30 / 产品构思交接 1.0。当前工作标题《重返木卫三》；原小说名为《重返木卫六》，旧目录名只是历史标识。

## 接手时先知道这六件事
1. 这是约一小时的单人线性第一人称射击战役：双主角陆闻川、周延；人类叛军占领木卫三十年，援军终于抵近。
2. 故事核心是复仇与保住光复机会之间的取舍。陆闻川存活，周延完成“允许同伴保护自己”的成长后负伤、救治失败。关系修复发生在死亡之前。
3. 木卫三已经历数百年地球化，寒冷地表可呼吸；自然重力约 1.428 m/s²。木星是同一方向的巨大天体，不能随镜头移动。
4. 战役按“序章＋三个完整主关卡＋尾声”组织，十二段剧情承载十四章小说。具体地图、代码、模型可以重做，不能再次把全战役压成一个小场地。
5. 最终用 Three.js 展现。资产采用自制、Hyper3D / Tripo 生成与已有可用素材混合路线，保留网格、UV、PBR、层级、骨骼与有效动画。
6. 当前原型只提供局部经验。全战役时长、成熟射击手感、人物演出质量和 Mac 性能尚未通过真人验收。

## 怎么带到 Mac
本目录是可直接复制的纯文档包。单文件 `HANDOFF.html` 内嵌全部正文、来源资料与 ZIP 内容，离线也可阅读；用 Safari 或 Chrome 打开，点击“下载完整 ZIP”，解压后让 Mac Codex 读取本目录。HTML 不需要当前电脑的服务、盘符或账号。

在 Mac Codex 中粘贴 [MAC_CODEX_PROMPT.md](MAC_CODEX_PROMPT.md)。该提示词先让接手者理解产品和检查当地工具，不自动扣费生成，也不自动改造仓库。

## 如何理解本包的标记
- **已确认方向**：用户明确提出或此前已经形成并持续采用的剧情决定。
- **设计起点**：尺寸、人数、分钟数、资产面数等调试预算，可以根据实机证据修订。
- **原型证据**：只证明记录中那个版本、那个测试条件下的行为；不等于最终产品或真人验收。
- **历史来源**：保留原文方便追溯，出现旧木卫六、旧速度和旧尺寸时，以本包分册说明为准。
- **后续建议**：本次交接提出的实施顺序或结构，尚未成为用户批准的比赛范围。

资料基于截至 2026-10-30 的项目文件和当前对话。来源目录没有 Git 仓库，因此没有源提交 SHA；不能写成已经冻结的开发版本。原型的测试记录与产品需求分开使用。
