# 05 · 玩法、演出与人类玩家体验

## FPS 的最低完整操作
| 功能 | 当前方向 | 接手时怎么核对 |
| --- | --- | --- |
| 移动 | 成人步行 2.1、奔跑 6.3、蹲行 1.35 m/s；无体力条 | 米制距离计时＋真人手感；不是 COD 实测参数 |
| 动作 | 骨骼素材按原速起步；移动倍率与动作播放独立 | 不把跑快变成动作快放，不把死亡慢放；步幅匹配后续靠合适动作与混合 |
| 鼠标 | 第一人称 Pointer Lock，ESC释放；恢复焦点清理旧输入 | 大角度连续转向、出入窗口、Alt/Command-Tab、重新点击不跳视角 |
| 瞄准 | 右键 ADS；瞄具、屏幕中心与弹丸方向一致，冲刺退出 | 正常比例下前后照门对齐，切姿态和换弹不漂移 |
| 跳跃 | 空格；自然重力 1.428 m/s²；现有起跳速度 1.65 m/s 仅为调试起点 | 头顶、台阶、坡面、移动中起落和落点碰撞；不把玩家弹出地图 |
| 射击与装填 | 左键射击、R换弹；少量主武器与手枪，最多两把为设计起点 | 动画、枪机／弹匣、发射和补弹时刻同步 |
| 蹲姿与交互 | C切换蹲姿，E情境交互；自由观察中的升降单独分配 | 多键并按、死亡、跳过、暂停后没有粘键或重复触发 |
| 自由观察 | 调试观察模式，明确暂停或隔离游戏控制 | 切回原人物位置与朝向，不改变任务和敌人状态 |
| 任务引导 | 世界目标可见；离屏时贴边箭头＋距离／方向，必要字幕回看 | 目标在背后、遮挡中、宽屏边缘都有可读提示 |

按键可以按 Mac 输入与测试重新映射，操作能力和输入隔离要保留。普通输入支持重新绑定是后续建议。儿童、剧情伤员、搬运状态有自己的限制，不影响正常枪战奔跑。浏览器快捷键与全屏要分别测试 Safari 和 Chromium；目前未在 Mac 验证。

## 弹丸与射击反馈
用户要求类似 PUBG 的有飞行时间弹丸。每发有位置、速度、发射时间，受当地重力与地球化大气阻力影响；碰撞沿上一位置到下一位置的线段扫掠，避免穿过薄物体。线段查询是飞行碰撞检测方式，不等于开火当帧直接命中全射程目标。

实际枪型、初速、阻力模型和伤害以后校准，不将某把原型冲锋枪写成最终制式武器。弹壳、落物与弹丸使用同一重力条件；牵引鞋只解释人员接地，不改变子弹下坠。视觉上不是每发都显示长发光激光线；可用有限曳光、命中尘屑、弹孔和声音表达射击。枪口不能穿墙后从墙后发射，近墙需阻挡或收枪处理。

后坐力、持枪摆动、镜头起伏分层，能降低晃动。换弹是完整片段加出入混合；稳定预备姿态与连续呼吸不要半段硬回循环起点。持枪手、握把、扳机、弹匣和枪机各自正确接触。

## 敌人与同伴
敌人至少能：观察、接近遮护、举枪射击、压制、换弹、短距离换位、丢失目标后寻找、受击、死亡。视觉与听觉有可解释边界；失去视线不能隔墙精确追踪。进场前有道路、声音或队友报告，不能在视野内生成；玩家提前到入口时推迟未进入的补组。

敌人分组入场，伤亡、任务进度和可读压力共同控制节奏。守点压力来自后续队伍接近、场内换位与任务进行，完成撤离或关闭入口后停止补兵。清得快可以更早推进；不设最后一人无敌、藏怪拖时间或无限刷兵填分钟。

队友有实际位置、射界和职责，会让开唯一通道与玩家枪口。技工修设备、医护转运、家属等待，再沿明确安全段移动。没有平民随机减员、隐藏救援倒计时或玩家友军伤害分支；对友方开枪给停火反馈。关键NPC不因玩家慢几秒而在背景死亡。

普通敌人死亡后终止AI与瞄准、完整倒地到地面、保持短时尸体，再淡出或在不可见时回收。原型约第12—15秒淡出是可调值，不是所有场景必须相同。周延的剧情死亡按医疗表演保留，不能套普通尸体自动消失。

## 容错与关卡完成
每次接敌有完整观察／恢复遮护，可看见下一处遮护和任务方向。近处换位先试约4—8 m暴露段，较长段给支援与分段遮挡；数值随6.3 m/s奔跑实测。玩家主要换位区争取2.4 m以上净宽，NPC不堵住后退口。低掩体看射界，高掩体恢复、装填和转向。

反复检查：打空一梭、错位换弹、冲过首个掩体、漏听报点、仰头看木星、退回补弹、在护送等待时离开、跳跃到边缘、换班后不立刻走。若多次失败集中在同一位置，先修地形、预告和敌人方向，再调伤害。

普通战斗死亡回最近检查点；剧情固定重伤不扣空生命条伪装失败。检查点恢复人物、弹药、门、任务、波次和已知信息一致，通常以少损失几分钟推进为目标；已见长对白可跳过。常规脱战回血不抹掉剧情旧伤和重伤。

## 演出与可操作叙事
全部使用同一引擎内场景、模型、光照和状态，区别只在控制权：
1. 作战操作：玩家控制移动与瞄准，队友短句并行，不强扭镜头看剧情。
2. 工作操作：可走、可看、可交互，角色收枪；重要长句安排在这里。
3. 协作操作：提示即将占用双手，玩家确认后搬运／递交；事前可退出。
4. 专门演出：固定角色动作，通常允许限幅观察；身体接触、坍塌、受击才短时接管。明确归还控制。

情境动作以人物实际站位、手部抓持和接触为前提。进入演出不能把人物瞬移到另一侧，镜头不能穿过自己头颅或模型。救援、父子抱撤、探视是高风险动作，应先用代理人体试接触，不等成品模型完成才第一次验证。

镜头设计先写“玩家此刻必须知道什么”，再确定人物距离、视线、遮挡和声音。前景设备不能挡住交接或受击；按玩家可能看左、看右、站偏的位置复核。重要事实可由动作、短语音和字幕补足，不靠频繁强制转头保证看到。

## HUD、字幕与声音
- 参考现代军事FPS的信息层级：准星中央；任务在侧上方；弹药与武器在右下；生命／受击反馈克制，方向可辨。具体视觉用自有设计。
- 底部中央显示“人名：内容”，近旁与无线电可加简短标识；与准星、交互提示分离。可调字号，关键指令可回看。
- 剧情人物与队友标记不穿过实体墙把所有信息暴露；任务点离屏指示仍能帮助找方向。
- 枪声、命中、危险方向和短报点有优先级；长争执不与多向交火重叠。建筑内外混响、遮挡与距离有变化。
- 九名具名人物声线可辨；配音文本按实机而不是朗读整部小说。免费或本地TTS尚未选型、安装或验收；交接不假定已经有成品声音。
- 医疗段保持工作声和停顿，死亡由医生明确告知，不全靠音乐或画面变灰暗示。

## 场景与视觉要求
写实尺度、冰质地形、隔热支座与清楚的建筑落地关系；墙体、窗带、管架和货物不互穿。近处掩体要能读用途和磨损，中景读清街区与工序，远景接冰脊、城市和木星。

原始网格、UV和材质层次优先保留。导入后排查材质组重复绘制、变换未应用、巨大包围盒、碰撞和可见几何不一致。雾、烟、景深、过暗曝光不能遮住问题或目标。实际第一人称画面与自由观察都要看，不能只看好看的固定镜头。

## 最低验证记录
每个切片至少留下：实际可操作入口；正常速度的视频或连续截图；玩家路径与碰撞复现；敌人入场／同时活动／实际射手／玩家和队友击杀分别计数；任务进度；死亡／重试；机器和浏览器信息；未解决画面问题。自动化可以证实某条路径通过，不等于人类玩家觉得成熟、自然或达到目标时长。
