# 《重返木卫三》科幻设定稿 v1
日期：2026-10-25。工作稿，供小说修订与约一小时线性 FPS 共用。根据本轮用户方向，将故事承载天体设为木卫三 Ganymede（盖尼米德），采用已具备露天居住条件的远未来地球化背景。

本稿确定环境规则与人物生活背景；对应地图见 [木卫三地图设计 v2](map_ganymede_v2.md)。既有小说是迁址前的原作，人物因果继续以 [SOURCE_BIBLE](source_bible.md) 为依据。本轮不写小说正文，不制作模型或代码。

## 1. 世界的基本面貌

木卫三是一颗有大气、可以呼吸、仍然寒冷的工业卫星。人类经过数百年的建设，让这里的天空出现云，让居民能穿着保暖工装走到街上。木星长期悬在朝向它的半球上空；孩子从出生起就知道它的方位，却未必见过地球。

故事发生在这项工程已经进入日常维护阶段之后。供热站、学校、港口、修理铺和医院共同组成故乡。殖民初期的地下设施仍在使用，露天街巷已经存在了几代人。被占领十年以后，居民依然维护着这套生活，只是可用的零件越来越少，公共服务逐渐被关卡、配给和军事征用割裂。

本作的主角要夺回一座能让援军进入、伤员离开、普通人继续生活的港口。环境工程给行动提供具体对象，不另外引出一场拯救整颗卫星的倒计时。

## 3. 地球化怎样运转

### 3.1 磁场维持网

天然磁场承担基础结构，人工设施对其进行长期增强和调节。设施分布在轨道与地表，处理来自木星磁层的带电粒子环境，也应对太阳活动造成的扰动。它不是只朝太阳架起的一面盾牌：木卫三通常处在木星磁层内部，主要工程对象必须包括木星的磁场、等离子体和高能粒子。

技术中包含对粒子俘获与沉降区的控制；“磁场更强”不自动意味着每个地点都更安全。磁网、足够的大气柱、上层大气化学和建筑材料共同构成防护。不能偏转的辐射及次级粒子由其他防护环节承担，不承诺所有辐射归零。

地表公众看到的是维护站、检修排期、环境通报和少数远方设施。不存在肉眼可见的蓝色能量穹顶，子弹和人也不会撞上磁场边界。本作主线区域处于常规开放状态，不增加辐射计量条。

维持网采用分布式供能和储备。局部设备受损时，邻接节点分担并限制特定作业区，维修人员处理问题；不能通过打坏北闸的一只控制柜让整颗卫星失去防护。极端大范围失效属于另一部作品的灾难规模，本篇不采用。

### 3.2 大气来自哪里

主体气体以氮为主，氧分压接近地球海平面水平，其他成分由环境系统调节。氮源来自长期输入的含氮挥发物，氧气生产以本地水冰处理等工业为基础；同时处理氢的去向、氧化消耗和大气损失。气体不是由磁场凭空生成，也不是由磁力托住。

本稿暂以港区约 90 kPa 总压作为叙事参数。这是远未来建成环境的设定值，不是健康操作指南。按自然重力约 1.43 m/s² 粗估，大气柱质量约 6.3 万 kg/m²；若近似按全球铺开，总气体规模约 5×10^18 kg。该量级说明工程需要跨世代资源输送，不能写成十年占领期间用几台发生器完成。

低重力下的大气保留、极区凝结、长期逃逸与化学变化都由持续的行星工程管理。城市之间共享大气；离开供热区会更冷，但跨过一道门不会立刻变成真空。轨道交通、未改造的特殊工程舱和污染封闭区才需要各自的密封装备。

### 3.3 温暖来自哪里

木星系统约在 5.2 AU 处，太阳辐照度按平方反比约为地球轨道的 3.7% [6]。太阳能照亮地面，却不能单独保证本作的气候。

此前数百年的工程已建立受控的大气热收支，轨道设施与大尺度人工能源系统补充热量；具体全球能量预算保留为未模拟部分。城市另用聚变热源、工业余热和蓄热设施维持居住带。近地管网负责建筑、街道结冰控制及热水，不把几条地下热管写成足以加热全球大气的装置。

港口保持冬季城市的质感：本篇行动时室外约 -8°C，属于当地常见可作业天气；温暖室内约 16—20°C。可用生活区随纬度、地形和供热条件变化，远郊仍是严寒冰原。有人造水循环、小片植被和温室，不设覆盖大陆的温带森林或温暖海岸。

厚冰地基需要隔热、温度监测与可维护的桩基。供热管线与建筑基础分离，温水排入衬砌回收槽，不直接融化承载建筑的冰层。地面可见接缝、融冻旧痕和重新垫平的支座，这些痕迹承担地图层次。

### 3.4 为什么人不必穿舱外服

主角、技工和居民在本篇的常规室外区域可以直接呼吸。常用装备是保暖工装、手套、护目镜、头部防护；反抗军外加护甲和通信设备。必要的防尘或防烟面罩不等于压力头盔，面部表情不再只能留在室内表现。

危害来自交火、低温、冰面、车辆、局部烟尘和工业设备。本作不新增氧气、体温、饥渴或辐射生存条。伤员更容易失温，因此转运仍需要保温和遮风，但不安排全员穿越真空的流程。

门保留用途差异：普通生活门、防风双门、消防隔断、医疗隔离门、旧设施仍可密闭的应急门。正常进出不需要反复等待升压；老式气闸可以被改作风雪门厅。不能因为已有气闸模型，就把一切门都解释成压力边界。

### 3.5 重力单独处理

地球化没有提高木卫三的自然重力。2026-10-27 按用户要求改为木卫三实际重力弹道：本作主线涉及的港口、居住区、道路、检修栈道和作业平台均采用约 1.43 m/s²，不再沿用此前的 0.85 g 人工重力覆盖区。战士与港务人员使用牵引鞋、关节阻尼和助力护具维持接地、制动与搬运。这些装备是科幻假设，不会改变周围自由物体的重力。

人员、设备、弹丸、弹壳、积雪和落物承受同一自然重力；接触地面时，人员另外受到鞋底牵引和地面支撑。自由飞行的弹丸还受到地球化大气阻力。地图边界继续由地形、设备和道路组织承担，不安排重力突然切换，也暂不加入低重力跳跃关卡。当前动画预演没有实现完整人体动力学，不能据其步态反推重力数值。

## 4. 天空、地点与时间

### 4.1 港口的虚构选址

本稿将故事港口暂名为“冰脊港”，居民日常称“老港”。它位于朝木星的半球，两条古老冰脊之间的工程台地上。正式行政地名和地球纪年尚未锁定，主线不依赖某一真实命名沟槽或撞击坑。

为了先把天空方向讲清，选用一组虚构的几何工作点：纬度约北纬 10°，相对下木点向西约 74°。这里的经度是相对量，不能直接当作 IAU 地图坐标；假定下木点在赤道附近，忽略小幅姿态变化。

按该简化几何，木星位于真北起顺时针约 93° 的方向，即东偏南约 3°，仰角约 16°，盘面直径约 7.7°。当地港图统一使用北上、东右；C05、D01、C03 与 E02 的木星都在同一个方向，不能每到一个镜头就移到画面中心。

这是一组可实现的构图工作条件，不是某年某日的星历计算。后续若确定故事日期，应据星历校准太阳方向、木星姿态和小幅天平动；本轮不伪造具体天文时刻。

### 4.2 本篇采用的天空状态

行动发生在当地漫长白昼的后段。太阳暂设在西方，仰角约 8°；木星位于东偏南，仰角约 16°。在远日近似下，这组方向对应木星约 96% 受照、接近满相的凸相；明暗分界按同一太阳向量确定，不能独立绘制一轮满木星再任意放太阳。

选址也考虑第一人称观看：以 16:9、70° 水平视场为例，垂直视场约 43°。该站点的木星中心实际约 15.6°，上缘约 19.4°；平视时可在画面上沿内留出约 2° 余量。下调仰角通过站点变化完成，不改变盘面尺度。地形遮挡和大气透明度仍需后续画面检验。

木卫三潮汐锁定，木星方向基本不变。太阳日约 7.17 地球日，太阳的平均时角变化约每小时 2.1°；这个数值不是任意地点太阳高度的变化率。一小时流程不跨完整昼夜，S11 的短时间省略也不把天色从正午直接切到深夜。

有足够大气以后，天空可以出现冷蓝、灰蓝的散射背景和低云。具体颜色、云量与透明度是本作人工气候的美术设定，需要后续画面验证。长大气光程可能降低低空木星的反差；港区选在较干、能见度良好的时段，云层只间歇遮住盘面，不保证每次抬头都像无大气天体一样锐利。

本片先定薄碎云、冰原偏北风、坡脚轻微吹雪。主光仍来自西侧太阳，港口灯和天空散射帮助读人物；木星提供天空轮廓与有限反射光，不当自发光探照灯。极光只作为可能的远方现象，本篇无需出现；不把高纬极光随意铺在低纬战场正上方。

## 5. 工程史、占领与故乡

以叛乱爆发为“十年前”，以本篇行动为“现在”。以下是新增历史框架，不虚构原小说已经写过的年代。

| 相对时间 | 新增历史 | 留在场景里的痕迹 |
| --- | --- | --- |
| 叛乱前约三百至一百年 | 多代工程逐步形成稳定磁防护、大气与可居住热区；早期人员主要住在地下 | 旧压力门、深埋公共厅、观测井和人工日景屏 |
| 叛乱前约一百年至十年 | 常规露天居住发展，港区扩建，工程移民的后代成为本地居民 | 露天小院、学校通勤标记、风雪门厅、温室与公共热水点 |
| 叛乱当年 | 邵原一系人类叛军夺权，得到外环财团支持；公共设施成为军事控制点 | 避难厅和检修门的原有关系；叛军占用民用设施 |
| 占领十年 | 财团控制航运、关键备件和结算；地方技术人员维持生活系统 | 反复翻修的管网、删改的车次、被军事牌覆盖的公共标识 |
| 本篇 | 援军已到近处，反抗军争取港口接收能力 | 将被撤走的技工、需要转运的家属、恢复中的灯线与设备 |

维持生命的基础设施大多在当地，有储备与多路供应。占领者需要人口、工业和港口，因此仍会维护基本供能；它通过配给差别、备件分配、交通许可和征用施加控制。正常维修不能被写成居民支持占领的证明。

地球联合政府组织并长期参与这项工程，木卫三居民保有共同政治身份，同时拥有本地家庭、行业与记忆。“回归”落实为恢复共同的公共生活、通信、航运和援助关系；地球来人接续本地居民已经在做的工作。多数年轻居民从未到过地球，不必人人怀念一段不存在的地球童年。

十年等待仍是军事封锁、重型运输与护航能力重建的结果。文明曾有数百年和平建设能力，不意味着战争后能立即集中军用运输、突破轨道防御并安全登陆。地方维生系统能运行，也不等于居民有舰队和装卸能力自行结束占领。

## 7. 港口的产业与行动目标

冰脊港承担水冰加工、工程物资转运、维修与推进剂补给。水冰是可以就近取得的原料，含盐层与暗色夹杂是检测对象；金属结构主要靠输入、回收与工业供应，不把地表普通施工写成直接开采深部岩石地幔。

本篇要恢复的是一组地方接收能力：气象与通航信息、引导信号、泊位设施、装卸设备、技工岗位和伤员转运。远处联合舰队负责轨道护航与开辟进近走廊；本地小队负责让重型运输有地方安全进场。

北闸保护维修人员和内侧道路，西货廊让居民转运与接防能够连续，接收中心把这些成果汇合。舰队首批进场只打开后续光复的机会，木卫三大部分地区仍在占领之下。
