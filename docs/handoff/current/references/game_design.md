## 2026-10-28：战斗密度与移动速度修订

本节依据用户最新反馈与 V3 实机问题复核提出下一轮候选。双主角、十二段叙事、周延完成成长后牺牲、孟齐获救和首批援军进场的结局继续保留。旧段落中的人物目的、信息顺序与交接条件继续使用；下文旧时间表和每场人数属于历史预算。新数量尚未接入模型或游戏，也没有经过真人首通验证。

### 已采用的移动口径与现有缺口

当前成人玩家步行2.1、奔跑6.3、蹲行1.35米/秒，不设体力条。按住右键时使用机械瞄准并停止冲刺；C切换蹲姿，空格起跳，Q/E升降仅在自由观察模式使用。跳跃采用1.428米/秒²重力和1.65米/秒的初始竖直速度，理论最高约0.95米、同高度滞空约2.31秒；实际落点由场景表面决定。儿童、负伤和共同搬运单独安排，不能用伤员动作限制普通战斗中的奔跑。

原约3731.4米基础路径，在6.3米/秒全程奔跑的理想条件下约9分52秒。这个数值只是路程下界，不含停留、交战、交互与演出。全战役一小时需要由实际遭遇与人物行动支撑。北闸44人切片用于检验操作与交战；输入驱动程序的快速通关不能当作真人首通时长。本次降速依据用户手感反馈，不用移动速度补足关卡时长。

V3 主角全部采样轨迹约 4,080.1 米，包含战术往返与被转运。统一按 2.1 米/秒换算，纯移动约 32分23秒；去除部分战术往返后的既有基础路径约 3,731.4 米，约 29分37秒。按 0.7 米/秒全程步行则约 97分09秒。因此，路线已经存在明显的速度与预算矛盾，不能直接将“真实游玩约20分钟”当成测量结论。

原战斗稿把73名普通敌人分配给30.5分钟战斗，约每分钟2.4名入场敌人；E09仅9人却预算300秒。它既低估了可交战内容量，实际演示又没有让命中、占位和任务完成控制战斗结束。修订必须同时落实敌人密度和可操作因果。需要扩建的是交战纵深、侧翼通路、多个守点和增援进路；没有内容的长连接也应压缩。

### 增援怎样形成连续压力

**节点防守。** 敌军从已经看见或听见的公路、服务院、卸载入口持续分批到场。每批随既有敌人伤亡、展开和任务进度进入，保持压力但给装填、辨认方向和短距离换位留空间。完成撤离、关闭敌方通路或接防到位后停止补兵；在场敌人继续交战或沿真实道路撤退。已取得的进展不能因玩家后退而全部重置。

**前往任务点。** 把现在的空白连接变成若干有不同站位关系的交战：先远处观察，再清前沿，敌军沿侧巷或下一处掩体退守，玩家进入新空间后遭到已预告的增援。已清空的后方保留为补弹和回撤空间。不能只在终点站几个人，也不能每走几米就把敌人直接生成在眼前。

**任务结束。** 清场快的玩家能够更早建立通路、让队友前出和完成交接。进入关键操作前，近处威胁必须受到控制。战斗中的伤亡由命中与伤害结算，敌人不会到点自动倒下。持续增援与阶段目标绑定；玩家理解该守什么、保护谁，以及怎样结束当前局面。

**有限调试总量。** 表中的上限是一次标准流程的首轮内容预算。压力不足时先改变增援衔接、交战位置与目标进度；不临时无限追加不可解释的敌人。持续来袭的观感来自场内外换位、下一组接近和任务进行，不靠最后一人无敌或隐藏倒计时。

### 下一次交付应当能看见和操作到什么

玩家能自行走、跑、瞄准、开火、换弹、回撤和推进；自动播放只用于观察。弹丸命中改变敌人状态，伤亡和任务进度触发下一阶段，NPC通过真实路线完成工作。默认第一人称可玩，同时保留自由观察供核对。

同一北闸片段要覆盖向前推进、守点、侧翼变化与回撤，体现人数增加之后的动作与空间差异。字幕采用底部“人名：内容”，近旁谈话与无线电可分辨，关键协作时画面、身体动作和HUD一致。人物、枪械、掩体、灯光和声音须同时进入实际画面，不能只提供箭头或名单。

判断这一段是否值得扩展，观察普通玩家漏听报点、换弹失误、冲过第一处掩体、回退补弹时能否理解局面并恢复；也要让熟练玩家快速推进，确认不会被脚本强行等候。报告实际用时、入场总数、玩家／队友击杀、最大同时活动人数和具体画面问题。没有真人试玩时不得填写首通通过率，自动导航通过也不代表体验成立。

本轮完成资料核对与设计修订，没有修改运行中的演出、模型或旧审计记录。实施从上述可操作片段开始，验证有效后扩展到其余遭遇。

### 统一的控制权说明
所有剧情均使用游戏引擎中的角色、灯光、道具与声音完成。以下是操作权限，不是不同视频制作方式：
- 作战操作：移动、瞄准、开火、换弹和情境交互；队友可同步说话与行动。
- 非战斗操作：可移动、观察和交互；角色主动收枪，开火暂停。
- 协作操作：玩家驱动一项短动作，例如推车或搬运；观察范围和退出位置由当前动作决定。开始前清楚提示会占用双手。
- 专门演出：由角色完成确定动作。优先允许限幅观察；坍塌、身体接触或受击等短拍可接管镜头。前后都有明确的收枪、动作开始与恢复操作过程。

不在玩家仍自由交火时突然扭转瞄准。长对白安排在局势稳定后；战斗中的必要指令保持简短，可通过字幕和任务记录复核。切换视点时显示姓名、时期和地点，手部装备与声音一并改变；不重演上一角色刚完成的整段战斗。

**剧情演出与控制：** 周延确认交接用短演出表现，接着让玩家亲自撤出。内门后收枪，周延坐下接受护具调整，听妹妹消息片段并作出简短回复；这些内容可伴随限幅观察与下一步准备。个人安排保持日常语气。角色已经接受自己需要休息，后面才能继续按这个变化行动。

**关系与后续回响：** 这是周延核心成长的完成段。S02中班长授予他的信任，现在交给孟齐与郑铎；S08保住的护送进度让此次交接按时发生。离开原位置后，现场任务仍在正常运转。

**场景、氛围与资产：** 复用ENV-D，但以“从守住的位置走出来”为新的观看方向。接替队伍、仍运转的通讯与有人留下照应必须入镜。需要CHAR-MENG、CHAR-ZHENG、CHAR-ZHOU第一人称身体/膝部状态、接防队员，AN-08交接/护具调整组，家人语音和通讯终端。此处不新造英雄纪念物。

**退出及检查点：** 接替实际成立后保存；受保护的内门处再次保存。玩家停留只会得到下一步提示，不通过无限敌人或隐藏伤害逼他接受成长。任务明确要求与同伴撤回。

### S10 共同撤回｜47:00—54:00
**来源、视点、空间：** 第12章；周延；ENV-E设备廊交叉口至已保住的西货廊。战斗5分钟，非战斗操作0.5分钟，演出1.5分钟。

**主要事件与玩家目标：** 在已知机动部队反扑下共同撤回；孟齐腿部受伤，队伍协作转移；周延受致命伤，报告伤情并要求救援，随后两人均被接回。

**可操作战斗与交互：**
1. 沿设备廊推进，利用接防人员的支援处理前方有限敌群，走向早已建立的转运方向。
2. 孟齐受伤后，目标明确为压制近处威胁、让郑铎靠近伤员，再到协作位置。玩家仍可能在这段正常战斗中阵亡并重试。
3. 威胁条件满足、队友站位完成后，玩家确认“协助转移孟齐”，短暂进入双手占用的协作动作。真实完成把人交入近处遮护和转运接应，不用急按QTE。
4. 转移成果成立后，进入固定剧情演出。周延在尚未脱离交火的后续移动中受击；伤情与求援不再由战斗生命值结算。

**剧情演出与控制：** 接手协作动作前显示操作变化；手部抓持、同伴配合和人物移动自然带入演出。致命射击来自前面反复建立的交火方向，不能凭空出现处决狙击手。约90秒专门演出包括固定受击、报告伤情、接应及担架片段；担架上允许限幅观察，减少强制晃动。求援由周延主动说出，治疗和存活不做可赢可输的输入判定。其余非战斗操作预算用于准备协作和短段移动。

**关系与后续回响：** 周延救人时请求配合，中弹后接受别人来救自己。孟齐已获救、转运路线仍通、任务已交接三个结果保持有效。周延的退场不会把此前操作抹成白费。

**场景、氛围与资产：** 使用ENV-E此前未正面交战的设备廊交叉口，随后接回S08清出的西货廊。提前可见储料方向及可能进入的敌群，避免旧场景无预告刷新。需要CHAR-ZHOU右侧伤情、CHAR-MENG腿伤、CHAR-ZHENG、医护组合，PROP-06转运车、PROP-09担架/医疗包、AN-09三人协作与第一人称伤后转运组。它是全片最高动画与控制衔接成本的一组。

**退出及检查点：** 交叉口战斗前、协作准备完成处分别保存。固定伤情开始后不出现“任务失败”，不显示可治疗倒计时，不以重试按钮暗示能回避死亡。演出跳过后直接进入两名伤员已送达的S11。

### S11 救护点｜54:00—58:00
**来源、视点、空间：** 第13章；陆闻川；ENV-F旧检修站。非战斗操作1.5分钟，演出2.5分钟。

**主要事件与玩家目标：** 接到两人送达的消息，交接装备与资料，见到仍在求生并接受治疗的周延。医生随后确认抢救失败；孟齐存活，许岚也需要短暂休息。

**可操作交互：** 收起武器，接放周延的装备箱、把已有资料交给医师、进入允许探视的位置。可以先观察孟齐或安置区，但抢救流程不依赖玩家“选对治疗方法”。不设置寻找药物倒计时、复苏小游戏或能改变结局的隐藏物品。

**剧情演出与控制：** 150秒专门演出拆入抵达、探视、救治后的时间过渡、死亡确认与短暂陪伴，各段之间保留可移动和观察的间隙。单个集中夺控段以约60—75秒为上限目标。使用遮帘、医护来回和一次短时间转场压缩小说中的等待；始终留在闻川能看见、听见的范围。医生明确说明死亡，周延无长篇遗言。

**关系与后续回响：** 两人已在S08修复关系，因此伤痛来自失去。闻川暂时无法顺利处理简单交接，许岚与郑铎接住他；孟齐需要继续治疗，不重新站起来参战。

**场景、氛围与资产：** ENV-F包含登记台、救治隔间、等候和伤员安置。布置可重复观察的人和物，避免只剩一间空白死亡舞台。许岚与医生职责分开。需要CHAR-ZHOU重伤/死亡表演、CHAR-XU、CHAR-MENG受伤、CHAR-ZHENG、医生及护理组合，PROP-09医疗组件、装备箱，AN-10探视/握手/医生告知组。声音以近距离人声、医护动作和通风为主。

**退出及检查点：** 抵达前与死亡确认后保存。该段无玩家死亡和医疗操作失败。跳过时保留死亡已确认、孟齐在治、闻川接到联络的同一终态。

### S12 进场之前｜58:00—60:00
**来源、视点、空间：** 第14章；陆闻川；ENV-F至ENV-C接收中心。非战斗操作1.5分钟，演出0.5分钟。

**主要事件与玩家目标：** 如实报告损失和接收情况，接受郑铎帮助，传递医疗需求，开启接收通道。邵原已逃入占领区；舰队开始进场。

**可操作交互：** 确认已经整理好的本地报告，将医师需求交到接收终端；沿已清空的短连廊到接收中心，协助来接船的工人通过入口。没有“追上邵原”的新任务，也没有要求闻川突然指挥整场战争。

**剧情演出与控制：** 汇报中短暂停顿，郑铎补上部分内容，闻川继续完成。罗敬确认泊位，舰队通过通信回执确认开始进场；30秒演出分配给这两处，最后归还操作，让玩家开门或扶门引导人员进入。结束标记是接收工作开始、任务完成，而非全星光复。

**关系与后续回响：** 闻川把曾要求得到的完整信息交给同伴，也允许别人帮助自己。他仍有愤怒和悲痛，已能继续承担对眼前人的承诺。

**场景、氛围与资产：** ENV-C从检修状态变为可接收状态，灯线、工作台和人员职责变化清楚。BG-02泊位远景可见识别灯或运输舰接近轮廓，不制作着陆大场面。需要CHAR-LUO、CHAR-ZHENG/CHAR-XU的最后交接、港务工人，PROP-08接收终端、AN-11汇报与开门接收组、舰队联络声音。

**退出及检查点：** 完成接收确认，玩家完成门口动作，淡出并显示流程结束。章节重玩可从S12起点进入；没有续关所必需的悬置任务。

## 4. 操作、资源、反馈与失败
- 基础FPS：移动、冲刺、蹲伏、瞄准、开火、换弹、切换武器和情境交互；少量预设越障按场景需要使用。
- 武器范围：步枪、短卡宾枪、手枪三种基础外观，玩家最多同时携带两种。固定补给与拾取形成短期取舍，无制作或升级树。两位主角共享操作底层，以手部、服装、任务和动作习惯区别身份。
- 常规战斗伤害在脱离压力后恢复，保证短战役的推进节奏。剧情伤势单独保持：周延旧膝伤、右侧重伤和孟齐腿伤不会被战斗回血抹掉。
- 每次遭遇的主要目标是清出通行条件、保护执行中的同伴或完成交接。敌群与增援次数有限，进场方向先通过车辆、声音或可见通道建立。
- 工程、医护和护送NPC各自执行职责。玩家不用反复给每个人下命令；交互的完成会改变门、车、人物位置或工作状态。
- 暂不设平民血条、随机减员或玩家友军伤害。车队在遮护后等候，安全段建立后才移动；未解决威胁时停止推进并明确呼叫。向友方开火触发停火反馈，不额外产生人物死亡分支。
- 战斗中玩家阵亡，重读最近检查点；关键NPC不会在背景无提示地死亡。非战斗段不以迟疑、走慢、漏看演出来处罚玩家。
- 计划在每段起点及长战斗的小目标后设置检查点，通常损失不超过约3—4分钟推进；必须实测。重新开始恢复该点对应的人员、资源、门与剧情阶段。
- 关卡目标、必要对白与任务记录共同指引；不要求搜集文档才能理解主线。角色关系没有数值条，也无奖励玩家刻意牺牲同伴的隐藏评分。

## 7. 后续制作顺序与验证问题
本轮只完成规划。下面是后续工作安排，不是已经完成的试玩结果。

1. **关键切片白盒，约8分钟：** 取S09交接约2分钟、S10可玩撤回约4分钟、固定伤情约1分钟、S11死亡确认约1分钟。这是验证用压缩节奏，保持人物选择和事件顺序；用占位人体、第一人称手部和临时语音，重点检查协作接手、身体接触、控制权归还和失败归因。
2. **S08取舍验证片段，约3—4分钟：** 展示完整信息、固定人物决定和一段真实护送。观察玩家是否把未实现的追击理解成系统漏掉的可选任务；调整提示与信息载体，不增加虚假选项。
3. **全片白盒连通：** 走通12段，实测每段战斗、行走、演出和重试时间；先解决重复路线、NPC阻塞、声音被枪声掩盖、超时或过短的问题。
4. **按风险制作资产：** 优先AN-09救援、AN-10医疗、AN-01父子与AN-02受困；再完成其余角色表演和环境。场景装饰在空间成立后增加。
5. **整合配音、字幕和声音：** 对照实机修剪台词，保证战斗命令与安静交流有不同长度；核对跳过后的信息和状态。
6. **完整流程复测：** 检查启动、画面、输入、战斗/交互循环、结局与重新开始，以及最低显示目标的实际表现。此时再评估是否接近约一小时。

优先观察四件事：玩家是否知道自己当前是谁；是否看见护送使接替成为可能；是否能复述周延先交接、后受伤的顺序；是否把固定受伤误当作自己操作失败。只有实际游玩才能回答这些问题。
