# 《重返木卫三》场景、演出与资产制作需求
版本：环境 v2。对应 [逐段制作规划](game_design.md)。以下为需求与工作量范围；迁址前 r05 已有外景模型、预览与 GLB，不能据此认为本版新环境、人物和演出已经制作完成。

2026-10-25 当前环境：[木卫三设定稿](world_ganymede.md) 与 [地图 v2](map_ganymede_v2.md) 采用有大气的寒冷工业港。C05、D01、C01 与部分 E02/E04 露天；人物可穿保暖服露面，地下旧设施与地表生活并存。木星位于东偏南、仰角约 16°，太阳暂在西方、仰角约 8°；天空与光照是一组共同条件，后续不随镜头独立移动天体。

2026-10-28 北闸操作修订：掩体应先属于港口的生产和生活。前沿保留原网格货箱，配套托盘、绑带和装卸标线；封签显示备件延期、占领方征用、空气滤芯更换。Godot TPS的悬浮叉车网格改作停用牵引车，维修托架、电芯等待通知和断开的充电线共同解释停放原因。后方用医疗电源和撤离携行物资交代工人的处境。旧E04高低水泥灰盒在当前入口停用，由这些可见实物承担碰撞和遮护。

建筑修订只在原有窗带上补齐窗框，停止对已经有立面的建筑再次自动铺窗；源建筑网格、UV和原窗层继续保留。机械瞄准使用原枪械的前后瞄具位置。持枪采用稳定的原作者预备姿势、连续呼吸和受击弹簧回弹；完整换弹片段有出入混合。2026-10-29修订明确：走跑片段按素材原速播放，移速调整不改变动作节奏；持枪与镜头起伏采用原始步态周期。死亡使用原速Death01，约1秒倒到地面，完整2.4秒收尾后保留尸体，第12—15秒淡出。所有动作观感须在正常播放速度下检查。

## 1. 画面与镜头原则
本作的冰岩防护居住区与地表货运港长期使用、反复维修。近景以人体、工装和设备为尺度，中景读出院落、管架与廊桥，远景接上冰脊、城镇和木星。人物有明确工作身份，公共设施保留占领前后的使用痕迹。写实比例与第一人称近距离互动优先；新环境仍需以可玩空间和代表画面验证。

- 人物、通路、掩体和可交互对象先可辨，再增加烟尘与装饰。每个战斗区应有稳定地标和清楚的退路方向。
- 重要关系用站位表现：前期周延站在出口或终端前替闻川安排；修复后两人共享信息；S09孟齐占据周延交出的掩体，周延从他的掩护里走过去。
- 默认保留第一人称。监控画面由场内设备呈现，不变成自由的全知镜头；受伤、被抱走和被抬走均保留人物身体与空间接触。
- 儿童与成人使用不同眼高和手部比例；年轻周延与成年周延保持可辨识的身体/装备联系。
- 对战斗关键目标同时使用轮廓、位置、动作、声音和必要图标，颜色只作补充。深色场景必须能分辨工人、队友和持枪敌人。
- 常规段落的开火、移动和瞄准不被表情镜头打断。专门演出开始前通过收枪、站定、抓持等动作交接控制权。
- 环境损坏使用事先制作的几个状态，优先保证连续性。全片不依赖任意墙面破坏或复杂动态解压。

## 2. 六组场景的搭建与氛围
| 场景 | 搭建重点与复用 | 光线、材质和声音 | 关键可读信息 |
| --- | --- | --- | --- |
| ENV-A 避难厅 | 等候区、主入口、防守柱、检修门和梯道共用一套真实相对位置；两名主角从不同一侧经历失守 | 旧公共设施的稳定照明逐步变为应急光；搪瓷、布袋、旧工作服比枪械特写更早进入视野；广播和人声逐渐被枪声压住 | 父亲在哪里、孩子已进入哪一道门、周延为何无法行动 |
| ENV-B 生活/后勤 | 三个紧凑空间用同一工业居住模块连接；墙面显示维修痕迹、替换零件、新标识盖住旧标识 | 节电照明、局部工作灯、虚拟日景；风机恢复前后声音不同；护士的工作话语有连续性 | 这里有人生活和维护；许岚与孟齐拥有自己的职责 |
| ENV-C 港务/接收 | C05 检修栈道接 C02 风雪门厅与 C01 露天生活院；C03 可见泊位，C04 保留立体骨架 | 暗色表层、冰质露头、隔热基础与旧管架形成尺度；院内有生活物件、短遮棚与被军车占据的通勤位 | 室内外关系、技工身份、家属去向和设备恢复结果 |
| ENV-D 北闸 | 露天下层装卸位、上层检修台与两个敌方入口；D02/03 挡风保温；三次使用改变站位 | 风雪、车辙、设备阴影与工作灯；枪声、车声具有距离和遮挡，东侧木星辅助定位 | 威胁来源、维修通路、高差、接防后仍有人守住的位置 |
| ENV-E 转运与设备通路 | E01 转运门廊、E02 分段开敞的跨沟廊桥、E03 设备交叉口、E04 安全回程 | 封闭、遮棚与露天段交替；湿暗地坪、吹雪与远景建立气候，车轮与工作声提示通路 | 车辆为何停、救援接力的方向、终章如何快速回到接收中心 |
| ENV-F 旧检修站 | 登记台、救治隔间、等候与安置区；提前布置可反复见到的家属和医疗工作 | 临时但整洁的医疗区域、布帘、工具与资料；对白、脚步和通风比音乐靠前 | 居民已经到站，孟齐仍在治疗，周延的救治与死亡已经明确 |

ENV-A与现在的生活区可共用墙体、门、管线的材质语言，但不把它们误做成同一间房。ENV-E的重复路段需要保留玩家能认出的门、灯和车，后续变化来自已发生的转移与战斗。

### 两组非可玩布景
- **BG-01 东货场：** 一辆军用车、车门、墙面与短出发路径，供监控摄像机拍摄邵原上车。使用真实引擎内角色与车辆；不需要可导航的完整车场，不作为玩家武器射程内的场地。
- **BG-02 泊位外景：** 连续冰质台地、暗色覆盖物、城镇轮廓、双臂吊架、泊位灯与运输舰远景。与 C05、D01、C03 的观看方向一致，木星与云层提供天空深度，结尾表现开始进场。运输舰细节可按预算缩减，连续地表和固定地标保留。

## 3. 具名人物资产
九名具名人物；年龄、服装与伤势属于各人物的状态，不按每个状态重新创造一个角色。除原文已有特征外，下列外观定位为设计提案。

| 编号／人物 | 模型与第一人称需求 | 表演、服装与伤势状态 | 使用段落及优先级 |
| --- | --- | --- | --- |
| CHAR-LU 陆闻川 | 成人第一人称手臂与身体、全身基础体；儿童比例手部与身体单独适配。成人面部以中景可辨为起点，不安排专属近脸镜头 | 成人维修工服/外加反抗军护具；手背擦伤连续；儿童外套与饭盒袋 | S01、S03/04/06/08/11/12；手部与抓持是重点 |
| CHAR-ZHOU 周延 | 成年全身与高优先面部，战斗第一人称手臂/身体；年轻状态沿用身份特征、更换服装与年龄表现 | 年轻驻军、成年混用旧护具、膝部不适、右侧重伤、医疗与死亡状态；伤势不能左右漂移 | S02、S03/05/06/07/09/10/11；全片最高表演优先级 |
| CHAR-FATHER 陆建平 | 可近距离辨认的成人全身与面部，熟悉的工作服轮廓 | 整理饭盒、交出孩子、拾枪、被击倒；不需要作战AI | S01；开篇关系成立的关键资产 |
| CHAR-ZHAO 赵启明 | 驻军身体基础加独立面孔/识别特征；近景需表达授权与被俘后的状态 | 正常分工、受伤、跪地、被处决；与普通守军一眼可区分 | S02；不能只做没有生前行为的受刑NPC |
| CHAR-XU 许岚 | 中近景全身、面部与工作手势 | 护理服、后勤外套、救护状态；分清护理组织者与医师职责。仅制作当前年龄状态 | S03、S06、S11、S12；医院连续性的关键人物 |
| CHAR-MENG 孟齐 | 全身、可辨识面部，护送与接防动作 | 搬物、分配位置、接替、腿伤、双人转运及在床治疗；结尾不再站立作战 | S03/04/07的反馈、S08/09/10/11；协作动作高优先 |
| CHAR-LUO 罗敬 | 蓝工服、年龄与家属关系相符的全身与中近景面部 | 护住家人、核对通信、主动回到操作台、执行接收 | S04、S08、S12；留岗必须通过行动可见 |
| CHAR-SHAO 邵原 | 独立可识别面孔；过去与当下的年龄/衣着变体 | 过去持手枪处决；当下整理衣袖、上车。无可玩首领战AI | S02、S08监控；两个时期要认得出是同一个人 |
| CHAR-ZHENG 郑铎 | 通讯员全身，中景身份可辨，可复用通用骨架与部分动作 | 携终端、护具帮助、共同救援、扶持与补充汇报 | S05/07/09/10/11/12；独立声音与装备保持识别 |

优先做好周延、父亲、赵启明、许岚、孟齐、罗敬、邵原七人的近距离表演条件。陆闻川以第一人称手部/身体为重点；郑铎通过中景、通讯装备和声音维持身份。

地图 v2 的地表装备：主角、反抗军、维修员与敌方人员使用保暖工装、手套、护目或头部防护，按战斗职责增加护甲。常规室外可露面；防尘面罩只在相应污染环境出现，不能默认都变成压力头盔。许岚、罗敬与家属可以穿外套通过露天转运段，伤员有保温与遮风措施。人物身份、伤势和衣物湿霜状态在室内外连续。本轮未制作新人物模型。

### 可复用群体
- **EN-01 驻军守军：** 基础人形、护甲、头盔、白识别带；主要为掩体射击与有限推进。无需每人独立面孔。
- **EN-02 机动部队：** 与守军同体系，增加可辨识的装备轮廓。威胁来自配合、方向和推进，枪械规则保持一致。
- **反抗军队员：** 共用身体和动作，使用旧工服与护具混搭、固定位置的队友识别标记。NPC身份要同时靠轮廓和提示辨认。
- **技工/居民/家属：** 成人基础体、工装和便服组合，有限不同面孔与年龄变化；儿童家属需要独立比例基础体。九名技工保持人数事实，近景重点留给罗敬与少数同事，其他人分组转移。
- **医护：** 医师一名重点中景角色、护理人员组合。口罩、服装和动作可以复用，但医生告知死亡的表现必须完整。
- 群众数量通过分组入场、前后遮挡和声音维持规模，不把所有群众同时作为完整战斗AI。

## 4. 道具、武器、车辆与状态
| 编号 | 必需内容 | 可见状态与交互需求 |
| --- | --- | --- |
| PROP-01 家庭物件 | 饭盒、布袋、检修包 | 父亲整理、孩子携带、撤离中掉落；保持同一外观 |
| PROP-02 维修工具 | 工具、检测表、格栅局部 | 手部能抓持，风机修复和门锁处理有前后差别 |
| PROP-03 信息设备 | 手持终端、工卡、无线电 | 任务图、预告、共享报告、家属确认、监控、私人语音分别有对应内容；不显示角色未获知的消息 |
| PROP-04 物资与记录 | 物资箱、补给箱、人员名单、装备收纳箱 | 搬运、交接、放置及医护核对；补给放在合理岗位 |
| PROP-05 场内车辆 | 通勤车与军用车两类 | 停靠、开关门、短距离驶离；无玩家驾驶与完整车损系统 |
| PROP-06 转运车 | 可推行车体、人员固定与坏轮状态 | 停车、移交、换车、车轮通过接缝；不能和手臂/伤员明显穿插 |
| PROP-07 门及控制件 | 检修门、防护门、控制盒与锁杆 | 开闭、卡住、解除、手部接触；根据场景共用结构并保留识别 |
| PROP-08 港务设备 | 接收控制台、局部升降机、状态灯 | 停用、检查、运行、可接收；远处机械结果与控制台信息一致 |
| PROP-09 医疗组件 | 担架、医护包、呼吸罩、床、布帘与必要管线 | 受伤转运、探视、处理、死亡确认；仅制作镜头和交互需要的部分 |

武器为WP-01步枪、WP-02短卡宾枪、WP-03手枪。第一人称需要持枪、射击、换弹、切换、收起与恢复；第三人称对应动作保持方向和物件一致。邵原处决使用手枪动作，父亲拾枪使用步枪动作。旧驻军、反抗军和叛军可共享武器结构，通过磨损与装备来源区分。

特效需求包括枪口/命中、局部尘屑、一次性坍塌、设备火花、伤势衣料变化、监控显示和泊位灯。密集烟雾不遮蔽必要目标；高成本破坏优先采用有限预制状态。

| 编号 | 内容、人物和使用段落 | 接触、视角与控制权重点 |

先用低精度人体和代理道具检查AN-09、AN-10、AN-01、AN-02。身体接触和控制权顺序成立后，再制作面部、手指和服装细节。其他组尽量以共享站立、交接、通讯和走位动作组合。

## 6. 声音、对白和字幕
- 对白按当前任务和人物意图重新编写，不朗读整部小说。强制主线对白与无线电先按约3,600—4,600汉字估算，许多与操作重叠；最终长度依据实际配音与试玩回调。
- 陆闻川说话具体、急时会打断；周延开始习惯核对，后期会报自己的需要；孟齐直接、熟悉现场；罗敬先问家属再谈设备；许岚优先处理正在发生的护理工作。双方的修复要保留局促和实际任务，不扩成演讲。
- 九名具名人物都有可识别声线，另需医师、舰队联络及有限群众包。年轻与成年状态的配音组织后续确定，不把年龄变体当作同一份无调整录音。
- 枪声、命中、队友警告优先于背景闲谈；必要长句安排在安静区或等待间隙。字幕标明说话者，允许缩放和回看，避免阅读区域遮住准星与近处交互。
- 空间声音有连续性：风机、门、车轮与无线电伴随玩家移动；室外风、交火和车辆声按距离与遮挡传播。监控没有拾音时，不凭空播放贴近耳边的现场爆炸声。
- 音乐在关系转折和进场时适量进入。S11给医生的明确告知与人物停顿留位置，不用持续音乐替代事实。
- 支持降低镜头晃动、抑制强闪烁和静音游玩。关键威胁与接收反馈均保留可读画面或字幕。

## 7. 优先级与成本收缩
**必须保留：** 双主角手部/身体、核心近景人物、六组空间的主线通路、宿舍营救、西货廊护送、真实交接、共同救援、医疗确认、接收反馈。S09离开掩体与S10协作转运不能用黑屏替代全部过程。

**可收缩：**
- 东货场只做监控所需范围，泊位运输舰只需远景或识别灯。
- 生活区减少可进入房间，群众减少独立面孔和支线对白。
- 地方建筑与设备共用模块，通过用途、损坏、灯光和人员状态区分。
- 背景群体的动作组合与物件可复用，重要的父子、交接、救援、探视接触单独校准。
- 减少连续交火波次和低信息量往返，优先保留玩家看得见后果的操作。

目前最大的未验证成本是AN-09第一人称协作、S01儿童抱撤、S11近景表演，以及货廊多人通行。这些应先通过白盒和动作代理判断，再投入成品资产。
