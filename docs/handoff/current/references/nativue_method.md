# Nativue 方法说明（随包摘要）
资料日期：2026-10-30。此文概述本次实际读取的Nativue Skill及analysis／roles参考，不是可安装的Skill副本。

Nativue的用途是建立带源码依据的语义架构画布，或在已选定的A/B/C协作模式中记录开发与独立验收。它要求先发现工作区、CLI、仓库与真实能力，再通过init／doctor／scan／analyze建立状态，不能从目录名臆测模块。

原生分析必须使用本次生成的analysis-request及真实inputId，证据使用扫描索引中的相对路径和有效行号。模块、关系、旅程区分observed、inferred、verified；verified需要相应的行为证据，不把文档推断写成实测。

台账写入通过CLI并尊重revision；不手改运行JSON绕过状态检查。.nativue属于本机状态，公共模板不传凭据、运行时绝对路径或模型配置；远程同步需要单独选择。

A管理范围和依赖，B开发并提供真实提交，C在独立上下文按对应提交检查。自己的不同角色标签不能构成独立验收；用户验收来自真实反馈。当前任务只是产品资料交接，没有创建任何这些运行记录。

本包据此提供可追溯产品图、来源索引、建议任务与未验证项。目标Mac应使用其实际安装版本的完整Skill与CLI帮助，重新生成原生状态。无法找到CLI不等于可以伪造扫描结果。
