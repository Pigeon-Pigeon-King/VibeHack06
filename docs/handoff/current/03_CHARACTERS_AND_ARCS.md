# 03 · 人物、关系与成长

## 陆闻川
现在十九岁，序章九岁。本地维修工兼反抗军成员；陆建平与许岚的儿子。熟悉风机、门机、融冰排水、工服标识和检修通路。他已经会照顾熟人、完成工作，不能把开篇成年闻川写成只会愤怒的空白人物。

外在愿望是追上邵原，内在问题是怎样让自己的痛苦与眼前人的责任共存。长期追踪确实帮助识破撤港，因此复仇投入有现实价值；后段放弃机会才有损失。争执中他有理由反对隐瞒，也必须为“周延怕事”的不公指责负责。

成长证据依次是：继续履职；主动收回伤人话；在完整知情、追击仍有可能时留下护送；让孟齐按时接防；失去周延后如实报告并接受帮助。结尾不是突然宽恕邵原，也不是宣布彻底不恨。

呈现重点：第一人称手部与工具熟练度，观察工装和设备后的判断，忙碌中的短句，怒意下仍完成交接的动作。名字的隐约联想留给读者，不另写一段解释“闻川”的寓意。

## 周延
现在三十三岁，序章二十三岁。原驻军战士，赵启明的部下；被救后加入地下反抗，成为战斗负责人。他与闻川经许岚结识，关系从照看幸存孩子发展为共事。

他并非没有私人生活，而是总把休息、家人消息和自己的需要推后。幸存被他理解成欠死者、欠医护的债；不断承担风险和掌握全部信息让他感觉自己仍在偿还。隐瞒情报是这个习惯的错误表现，不能用“他早知大局所以没错”抹掉违约。

成长依次发生：承认隐瞒；交出可靠消息与不确定项；采用孟齐的专业建议；说出伤腿和换班需要；核实接防后离开阵位；接受护具调整与保护，回复家人、安排接下来想做的事。**S09／第十一章完成内在转变。**

S10 是以新方式行动：救孟齐时请求配合，中弹后主动报伤和求援。两人成功送达，周延仍因伤势死亡。文学上退场发生在成长完成之后，情节上死亡有已建立的军事原因。不能把成长改成独守到死、拒绝救援、突然新增必死任务，或只在遗言里说“我终于相信你”。

呈现重点：前期替别人检查、站在终端前过滤消息；后期把终端与位置让出来。接防队员实际占位、郑铎调整护具、孟齐掩护他走过通路，比独白更重要。

## 配角的独立职责
| 人物 | 自己想完成的事 | 关键行为与命运 |
| --- | --- | --- |
| 陆建平 | 保护孩子和正在撤离的人 | 普通维修工，抱怨和笨拙的日常也存在；先送孩子，后拾枪死亡，不追加秘密英雄身份 |
| 赵启明 | 组织居民撤离、让部下能判断 | 生前向周延授权；受俘后被邵原处决，信任在后来的换班中回响 |
| 许岚 | 完成护理和人员转移 | 闻川母亲、护理组织者，有自己的同伴与职责；死亡诊断由医师承担 |
| 孟齐 | 把人员送达，再完成接防 | 熟悉车辆、通路与交接；方案先被验证；腿伤后存活并继续治疗 |
| 罗敬 | 保护家人，判断自己还能做什么 | 九名港务技工中的重点人物；家属安全后自愿留岗；完成接收工作 |
| 邵原 | 撤走亲信与技工，破坏不能带走的能力 | 人类叛军指挥官；十年前暴行执行者；监控中确认撤离，结尾逃入占领区 |
| 郑铎 | 保持通信、协助接防和救援 | 真实接手职责、帮助周延、救援孟齐，最后补充闻川的汇报 |

沈玉芬是罗敬的妻子，原作还涉及孙辈与其他家属；不必新增大量具名近景角色。医师承担抢救决策与死亡告知。九名技工属于原作群体，北闸原型的七名工人是局部任务计数，不是把全片技工总数改成七人。

## 关系变化必须按顺序发生
| 阶段 | 两人关系 | 先有的证据 | 玩家能看见的变化 |
| --- | --- | --- | --- |
| 十年前 | 各自承受失去，还不是战友 | 父亲保护撤离者；班长信任部下 | 两条有限视点，不杜撰同时目睹全部事实 |
| 出发 | 熟悉、尊重，但仍不对等 | 闻川会做事；周延反复替人核对 | 约定可靠情报共享，护送完成后换班 |
| 营救 | 共同目标暂时一致 | 闻川识破异常，孟齐解决交接 | 周延采用闻川判断，承诺保护家属 |
| 隐瞒与争执 | 信任受损 | 周延主动扣住消息 | 闻川继续做事但不再无条件接受安排 |
| 公开与修复 | 重新成为共同判断的同伴 | 完整消息、路线与人手代价 | 周延先改变做法，闻川随后收回不公指责 |
| 取舍与换班 | 对彼此的承诺得到结果 | 护送完成，接防人员有时间回来 | 闻川留下；周延离开自己的阵位并接受保护 |
| 伤亡之后 | 已修复的关系被战争截断 | 周延已想活、已学会求助 | 闻川悲痛但不陷入“没来得及道歉”的唯一逻辑 |

## 写作与配音的尺度
单段只提供当前人物能知道的信息。叙述和镜头避免全知反派视点。人物通过做事、停顿、打断、递物与让位表现关系，减少总结主题的台词。底部字幕显示“人名：内容”；每人声线可辨，战斗命令简短，关键争执与医疗对白在安全时段展开。固定结局不设计伪分支或假装治疗可以成功的小游戏。
