# 01 · 产品方向

## 一句话
在地球化后的木卫三，一名追查杀父仇人的年轻维修工和一名背负幸存负担的老兵，必须在援军抵近之际夺回港口接收能力。玩家通过推进、守点、护送和换班，经历他们怎样把个人复仇放到共同光复之中。

## 玩家最后应记住什么
天空中木星一直在原处；有人已经见不到恢复工作的港口。玩家亲手保护过的工人、车辆、伤员和通信，最后让第一批运输舰得以进场。故乡的回归体现在这些具体结果里。

陆闻川没有放下全部仇恨。他知道追击机会确实存在，也知道抽走护送和换班力量会让谁承担代价。周延没有用死证明忠诚：他先学会交出位置、接受保护并打算活下去，之后才在共同撤回中受伤。

## 已确认的产品边界
| 维度 | 当前方向 |
| --- | --- |
| 类型 | 单人、线性、固定主线、双主角第一人称 FPS |
| 篇幅 | 完整作品约 60 分钟；普通难度首次正常通关 55—70 分钟是待验证目标 |
| 结构 | 序章＋三个主战役关卡＋尾声；12 个叙事段落，10 组战斗遭遇 |
| 情绪 | 严肃战争、占领生活、具体的人际责任；悲剧结尾中保留真实成果 |
| 世界 | 木卫三，远未来地球化后的寒冷工业港，有大气、云、风、冰脊和露天街区 |
| 技术终端 | Three.js；桌面键鼠优先，预留手柄与可调字幕；开发转到 Mac |
| 美术 | 写实人体比例、可信工程与生活痕迹、克制军事科幻；COD Modern Warfare 是阅读与操作体验参照 |
| 演出 | 过场与即时演算合为同一套引擎内演出；逐段规定控制权 |
| 资产 | 自制＋Hyper3D / Tripo＋现有可复用素材；可以重新制作具体地图 |
| 语言 | 中文对白与底部说话者字幕 |
| 结局 | 周延死亡，陆闻川、孟齐存活，邵原逃离；只争取到援军进场机会 |

不扩展多人、开放世界、基地建设、技能树、制作树、载具驾驶、太空战、低重力跳跃解谜或分支结局。移动有跳跃功能，但地图不依赖高难跳台。主线没有饥饿、体温、氧气或辐射数值管理。

## 五项体验要求
**战斗要有行动目标。** 枪战为开通道路、保护作业、护送和接防服务。敌人倒下、同伴占位、居民通过和设备恢复共同推动阶段，不能靠播放时间结束战斗。

**世界先有用途。** 北闸原本是称重、安检、维修和通勤场地。车辆、货架、维修机组、征用物资自然成为掩体；每块遮护都能解释为何在这里。

**地图容得下真实的人。** 首次玩家会看错方向、空枪换弹、冲过掩体、后退和漏听报点。路线要给观察、交火、恢复和再推进留空间，群众与战斗人物不能挤在同一条轨迹上。

**成长要变成行为。** 周延共享信息、采用孟齐方案、让别人接替；闻川兑现护送承诺、承认不公指责、最后如实汇报并接受帮助。玩家看见这些决定的结果。

**画面与声音共同成立。** 同一片段要同时有合适模型、比例、材质、灯光、动画、枪声与操作反馈。只有一张好看的鸟瞰图、箭头路线或自动演出视频都不足以证明完成。

## 保留什么，重新做什么
保留：人物关系、信息顺序、主要事件、地图的地理职责、天空一致性、操作需求、试玩发现和可用资产。

可以重新做：房间布局、路线细节、敌人部署、地图长度、技术架构、具体枪型、灯光方案、所有不达标的模型与动画。现有原型是参考，不是必须迁移的技术底座。

完整战役始终是产品目标。比赛若先做片段，必须明确叫“战役切片”，并保留后续三关结构；本次没有把用户的目标改成几分钟小样。

## 衡量是否接近目标
真人能说清当前是谁、要保护谁、敌人从哪里来，能犯错后恢复，能理解复仇机会的代价，也能复述周延“先接受换班，后负伤”的顺序。全程计时按互斥活动记录，画质与性能在实际 Mac 和浏览器测量。当前没有全战役真人通过率、平均首通时长或统一 60 fps 的证明。
