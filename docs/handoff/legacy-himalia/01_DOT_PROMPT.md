## 目标与职责

作品是约一小时、双主角视点、固定主线的单人 FPS。第一人称战斗、交互和剧情演出共用同一套空间与资产。参考附带制作规划理解镜头、人物站位、门和设备的作用。

你负责环境模型、场景道具、材质、灯光、场景状态、摄像机、剧情走位标记及必要的角色代理体。需要交付全部八组场景，不能只制作一个示范房间。场景应具备可继续进入游戏引擎制作的组织结构，同时能够直接在 Blender 里检查和预览。

3. 先检查 ENV-D、ENV-E、ENV-F 的接防—共同撤回—医疗路线，以及 ENV-A 的父子撤离和周延受困视线。用人体、担架、转运车代理确认尺度和接触空间。需要调整时保留原阶段文件并另存新版本。
4. 给全部场景补齐模块、关键道具、材质、照明和状态变体。环境采用写实比例、长期使用和反复维修的岩下工业风格，控制纯装饰物数量，优先完成近处玩家会接触的内容。
5. 建立 S01—S12 的第一人称检查摄像机、人物走位和事件标记；给门、终端、车辆和担架保留可编辑的轴心与部件。演出预演使用同一组资产，不另建一套只有电影镜头能看的假空间。
6. 覆盖八组场景生成预览图与俯视图，并保存关键交互的检查截图。确认工程可重新打开、资源没有缺失；验证完成后交付下载文件及清单。

## 美术与空间要求

- 使用真实米制尺度。人工重力下的人物活动按常规步行处理；不添加零重力战斗或需要真空装备的可玩室外段。
- 光线为可操作阅读服务。门、敌我位置和交互面在普通曝光下能看清。烟尘、应急灯和明暗对比应保留通路辨识。
- 保留日常生活痕迹：饭盒、旧工卡、修补板、工作灯、护理记录、车轮磨损、不同年代的设备标签。不要用到处一样的弹痕、血迹和霓虹代替地点身份。
- 成年与儿童眼高分别检查。儿童代理使用儿童比例；所有人物可用代理体，但要在清单里说明完成状态。
- 战斗区具备连接的掩护位置与可理解的敌方接近方向；居民集合区与交火区有真实遮护。无形空气墙不能承担空间解释。
- 全程固定主线。只在局部掩体与接近路线提供战术变化，不扩建开放世界、支线、车辆驾驶或太空战。
- 模型、材质和符号原创或使用许可明确且无需付费的资源。记录外部资源来源与授权；不购买、订阅或上传公开发布。
- 角色、门、伤员和担架的接触空间要实际检查。周延右侧重伤、孟齐腿伤的姿态和道具位置保持一致。
