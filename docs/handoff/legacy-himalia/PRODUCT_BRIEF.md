# 《重返木卫六》FPS 改编制作简报
版本：规划 v1。来源：已完成的《重返木卫六》小说 v1，全十四章。

本轮交付约一小时单人线性 FPS 的制作规划，包括逐段可玩流程、统一的引擎内剧情演出、场景与资产需求。后续首次运行验证建议以 graybox 为目标；本轮完成度是文字方案。引擎、工程实现与最终画面成色尚未选定。

## 已确定的方向
- 固定主线、双主角第一人称，陆闻川存活，周延牺牲。结尾只完成援军进场的条件。
- 人类叛军获得外环财团支持；十年等待来自封锁与运力重建。
- experienceProfile：hybrid。战斗和空间交互承担主要操作，人物取舍决定目标及后果。
- 十二段流程，基准预算60分钟：战斗30.5分钟，非战斗操作16.5分钟，专门演出13分钟。分类互斥；移动、战斗中同步发生的对白不另加时间。
- 时长按首次游玩、普通难度、正常推进并完整观看剧情估算，不含暂停、加载、死亡重试和片尾名单。首次通关目标区间55—70分钟，需后续实机测量。
- 演出全部在游戏引擎中完成，使用同一场景、角色与道具状态。是否交还操作权逐段规定。
- 主要身份：十九岁的本地维修工兼反抗军成员陆闻川；三十三岁的反抗军战斗负责人周延。序章分别使用九岁的陆闻川、二十三岁的周延。
- 中文对白与字幕。延续小说对占领生活、故乡联系、同伴责任的表达。

## 本轮采用的制作假设
| 项目 | 暂按此规划 | 后续影响 |
| --- | --- | --- |
| 平台、输入 | 桌面单人，键鼠优先，同时预留手柄输入与字幕缩放 | 更换平台时重新核定输入、镜头与性能 |
| 显示目标 | 横屏16:9；1080p、60帧作为后续验证目标 | 这是设计目标，未作性能证明 |
| 视觉 | 写实比例、工业居住区、克制的军事科幻；角色表演优先 | 不以电影级面数或大规模破坏作为前提 |
| 操作 | 移动、瞄准、射击、换弹、蹲伏、情境交互；战术位置可变 | 不增加技能树、制作系统或自由指挥队伍 |
| 内容表现 | 严肃战争与丧亲；暴力集中于动作及后果 | 处决和重伤以人物反应、空间阻隔与声音组织，不依赖解剖式特写 |
| 后续成色 | 首先验证可玩的白盒；全片最终制作标准另定 | 无需在本轮决定引擎或购买资产 |
| 工时、人员、费用 | 用户未给出；本轮不据此承诺开发周期 | 先通过关键切片查明动画、AI与场景成本 |

## 制作范围
采用六组主要空间、十二段任务、九名具名角色，以及可复用的敌军、工人、医护和家属组合。剧情顺序固定；玩家决定战斗方法、观察次序和短距离移动路线。小说中放弃追击、公开情报、接受换班属于角色的固定决定，玩家执行决定后的任务并获得可见结果。

本轮不制作代码、地图工程、模型、动画、录音或可运行版本。全片暂不加入载具驾驶、太空战、零重力战斗、多人模式、分支结局及邵原首领战。人物成长通过后续行为呈现。
