## 机器清单与配音交付

每个桥段含 id、from、to、heading、kicker、cues。heading 是下一段章节名，kicker 标明相对时间、地点或人物视点；默认只配 cues 内的 text，标题与提示语不进入旁白。

每个 cue 的 id 是后续配音条目键，例如 bridge-s01-s02-01。录音、字幕和验收应使用同一 ID；修改文字时按 ID 明确受影响条目，不因其他桥段增删而重新编号。仅与本桥语义对应的新句才新增 ID。文件中没有声音供应商参数、音频 URL 或声线审批状态。

readingSeconds 是暂无音频时的字幕阅读时长：统计汉字、字母和数字，不计空格与标点，按每秒 3.5 字估算，向上取整到 0.5 秒，至少 3 秒。它不代表实际配音长度。配音接入后按音频实测时间播放与结束；生产窗口应回交每个 cue 的真实时长和文件对应关系。

按用户要求，转场期间展示字幕并加载下一关，左键可跳过，旁白结束后自动进入。字幕按 cue 依次显示并自然换行；不要把整桥同时堆上屏幕或缩小字号。加载完成、跳过、暂停与音频结束的调度由转场模块接入验收。

当前共 11 个桥段、27 个 cue，正文计 684 个汉字／字母／数字，含标点共 753 字符。无音频降级阅读累计 201 秒（3 分 21 秒），单桥 15 至 21.5 秒；配音实际长度待录音后实测。

## 旁白语气

使用闻川B声线朗读克制、客观的第三人称叙述。读清人名、动作先后和地点，句间留自然停顿。时间跨度和视点变化需要清楚，死亡结果平实说出；不为后续受伤、死亡或逃离结果加预告式重音。声线选择不改变原文视点，也不把其他人物的经历改写成闻川亲历。

下列“承接与动机”“依据”“审稿边界”供制作人员核对，不进入玩家字幕或旁白。
