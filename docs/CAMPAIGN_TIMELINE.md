# 战役时间线与角色知情边界

整理日期：2026-10-31。用户要求后续关卡也与后面的时间轴对齐。本文统一 S03—S12 的事件顺序、角色知情与跨章因果，作为后续对白、任务、演出和存档对齐依据；不是全战役已经验收的声明。S01／S02 直接遵循 [序章统一时间线](PROLOGUE_TIMELINE.md)，不在此另写一套。

优先级为当前用户裁决 → [项目方案](PROJECT_BLUEPRINT.md)／[可执行体验设计](../design/GAME_DESIGN.md) → 当前交接分册 → 小说大纲及原作。原始来源保持不变；旧资料中的制作时码、旧天文与环境描写不能覆盖当前归并方案。

## 时间尺度与视点

- 序章发生在十年前；S03 起为十年后的同一轮港区接应行动，陆闻川十九岁、周延三十三岁。S03 合并原作第三、四章，游戏主视点仍是闻川，不因原作第四章用周延视点就临时改换玩家身份。
- 只固定相对先后：S03 是行动前准备，S04 开始实际行动；S05—S08 中港务、护送与战斗任务在同一行动中并行推进，切换视点不意味着另一线停止；S10 紧接 S09 的共同撤回，S12 接续救治结果后的短时间。没有确定故事年份、日期、钟点或每段真实经过分钟数，不自行补写。
- 当前世界方案是漫长白昼后段；“夜班”等标题可指工作班次，不能据旧小说的地球昼夜写法另排日历。旧 S 段绝对时码和约一小时／55—70 分钟均属制作或体验目标，不能直接充当故事内钟表或强制等待时间。
- 切视点后，玩家的见闻不能自动成为角色知识。世界已发生的事实、角色收到的消息、待确认的预告与具体报告来源要分开；后续回忆也不能让闻川在童年目击序章视线之外的事件。

## S03—S12 的唯一事件顺序

下表以完成事实连接段落。列出的次序不能用跳过、完成页文案或下一章默认值提前兑现；已成立的救援、护送和交接成果也不能因后续剧情伤亡而被撤销。来源代号与行号见文末定位表。

| S03 夜班与出发／闻川 | 日常维修与护理物资交接 → 集合确认舰队抵近、接应分工 → 约定可靠的邵原情报及时共享，护送完成后接防换班 → 领装备出发 | 闻川与周延知道共同任务及共享约定；闻川已有追查积累和生活责任。尚没有本次邵原动身确认。周延的家人消息／休息需要可以先建立，不能提前把 S09 的主动接受保护写成已完成 | W56—57；C40、52、55；L70；N73—99 |
| S04 带回港务人员／闻川 | 观察押运异常并报告 → 从后门接近、营救技工、实际交接人员 → 罗敬确认撤港／毁坏接收能力的安排，提出家人需求 → 闻川承诺保护家属，孟齐落实转运 | 周延依据闻川的有效情报调整安排；技工已被接回、家属保护承诺成立。安全交接位或暂时受保护，不等于后续整批护送已到医疗站，也不等于邵原本人已经动身 | W41、58；C41、54；L71；N103—113 |
| S05 北闸的预告／周延 | 防守北路 → 掩护工人经独立后路撤离 → 应对东侧压力、分批撤回 → 局势稳定后接收邵原转移预告 → 通报机动部队威胁，主动扣住转移时机 | 周延与玩家知道可靠预告及其不确定性；闻川只收到当前任务和机动力量的必要警告，尚不知道被扣下的时机。预告不是已动身。隐瞒是违约，不能改写成通信丢失或因“大局正确”而无错 | W43、59；C15、42、56；L72；N117—127 |
| S06 转接门与争执／闻川 | 检查并解除转接门阻滞 → 患者实际通过 → 从正常道路／人员更新得知周延此前已收旧报告 → 在安全设备间收枪争执 → 继续各自职责 | 闻川此时才知道旧预告被隐瞒；他反对违约有理，但“怕事”的指责不公。知道旧预告不等于拿到了 S07 更新后的全部来源、未知项和方案；争执结束也不等于关系已修复 | W43、60；C42—43；L73；N131—141 |

| S08 留下护送／闻川 | 确认罗敬家属已受保护／到站 → 罗敬自愿留岗，闻川收回不公指责 → 监控与联络可靠确认邵原动身，说明追击可行及其占用护送／接防力量的代价 → 闻川完整知情后选择履约 → 护送过桥、短协作换车、全部任务人员实际送达并交接 → 孟齐得以带接防力量返回 | 两位主角对决策所需情况一致知情，关系已修复到能够共同负责。放弃的是仍可组织的追击；不得先宣布邵原已经彻底逃脱再要求“选择”。罗敬家人的安全是留岗前提，本段其余待转运人员仍需实际护送；监控看到离开不等于确认他已进入内陆占领区 | P14；W45、62—63；C8、43—44、54、57；L75；N161—189 |
| S09 接受换班／周延 | 守住后线、核实护送完成报告 → 接防人员实际到场占位并接通通信 → 周延交出阵位，亲自沿同伴掩护线撤出 → 在内门接受护具调整、回复家人、安排休息与后续生活 | 交接已经真实完成，原岗位仍由接防人员承担。周延在此完成成长、愿意继续活；不是临终告别，也不能把正常看消息变成惩罚触发。此时孟齐与周延尚未承受 S10 的固定伤情 | P15；W47、64；C17—21、44、55；L76；N193—205 |

## 不得颠倒的跨章因果

| 因果链 | 对对白、任务与存档的要求 |
| --- | --- |
| 共享约定 → 扣住预告 → 发现违约 → 完整共享 → 确认动身与知情取舍 | S05 的周延私有消息不能直接进入闻川目标栏；S06 揭示旧报告不替代 S07 的完整更新；S08 以前不提前确认动身，S12 的逃入内陆需新的可靠确认 |
| 营救技工并承诺家属 → 家属安全后罗敬自愿留岗 → 护送人员送达 → 孟齐返回接防 | 区分技工、罗敬家属、本段患者／其他转运者与护送队职责；不能用一组人的安全状态给所有群体结算。S04 的承诺要在 S08 的实际结果中兑现 |
| 修通医疗通路 → 侧翼路线核实 → 护送／换车完成 → 换班 → 两名伤员送达 | S06、S07、S08 的通路成果支撑 S10 救援。不能从已安全的医疗后方凭空出敌，也不能为了剧情伤亡抹掉已救的人或已交出的岗位 |
| 周延先改变共享方式 → 闻川生前收回伤人话 → S09 接受换班与保护 → S10 协作救援、主动求援 | 关系修复和成长在负伤之前成立；不得移到遗言、死后道歉或独守牺牲中才完成 |
| 机动力量预告 → 持续跟踪 → 接防时施压 → 撤回时反扑 | 邵原运输人员先走不代表作战部队全部离场；S10 危险来自已建立的路线和交火，不能清场后新增处决者来强制伤亡 |
| 两人获救送达 → 真实救治 → 医师确认周延死亡／孟齐仍治疗 → 如实报告与首批接收 | 获救不等于治愈；固定救治结果不做可赢可输小游戏。S11 之后不得恢复周延指令或可回应状态，S12 也不能跳过损失与医疗需求直接宣布全局胜利 |

原大纲第七章概括为“信息差在本章消失”；按优先级更高的当前制作卡，落实时应区分 S06 发现被隐瞒的旧预告、S07 完整共享与 S08 确认动身，不能由这一概括提前兑现后两段。原作第三／四章合入 S03、第九／十章合入 S08，只压缩呈现结构，不把各自必要因果互换。
