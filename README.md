# 重返木卫三

Three.js 单人线性第一人称射击战役。开发环境为 Mac，最终目标为 Windows EXE。完整产品保留序章、三个主关卡和尾声，约 60 分钟是待实测目标。

当前 0.2.0 可连续游玩第一关前段：S03 夜班准备 → S04 接回九名港务人员，支持本机检查点与设置恢复。北闸、双视点序章、换班救援三个缩短白盒保留为独立验证入口。当前仍使用可替换的程序化占位资产，尚非一小时完整战役。三个原始 ZIP 均为文档包；当前代码是在本仓库新建的原创实现。

## 运行候选

```sh
npm ci
npm run dev
```

浏览器入口 `http://127.0.0.1:5188`。桌面容器用 `npm run build` 后 `npm run desktop`；Windows 候选打包用 `npm run package:win`。实际覆盖与限制见 [构建说明](build/BUILD_BRIEF.md) 和 [当前验证记录](artifacts/chapter-evidence.md)。首轮三白盒的操作证据保存在 [历史记录](artifacts/final-evidence.md)。

WASD 移动，Shift 冲刺，C 蹲伏，Space 跳跃，鼠标观察，左键／F 射击，右键瞄准，R 换弹，E 交互，Esc 暂停。方向键提供转向替代；Enter 只跳过允许的演出。暂停中可重试检查点、重开、调整音量／灵敏度与减少晃动。

主菜单“继续”恢复连续章节最近的检查点；独立验证场景使用分开的存档槽。“重开本场”重置当前段落，“从夜班重新开始”重置这段连续流程。存档使用当前浏览器／Electron 用户目录的本机存储；不同端口、浏览器和桌面容器不共享存档。目前没有跨设备同步或导入导出。后续完整 S01—S12 接入时仍需要正式的版本迁移策略。

## 当前推进约定

2026-10-30 用户选择尽可能覆盖三条验证线：序章 S01—S02、北闸 E04、S08—S11 人物取舍与协作演出。先共用一套输入、弹丸、任务、人物和演出接口，通过后扩展剩余战役；具体顺序见项目方案。验证线是开发步骤，不替代完整产品范围。

日常工作在 `main`。大改或并行工作前，先整理并提交主线，再将最新 `main` 同步到备用工作树的 `codex/vibehack06` 分支；分支验证通过后合回主线并检查整合结果。

用户已授权架构完成后持续制作，并允许占位资产先行。正式新资产先由 ImageGen 制作概念图，再进入 Tripo／Hyper3D 或 Dot 云端 Blender；先复用适合本作的已有素材。
