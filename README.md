# 重返木卫三

Three.js 单人线性第一人称射击战役。开发环境为 Mac，最终目标为 Windows EXE。完整产品保留序章、三个主关卡和尾声，约 60 分钟是待实测目标。

提交时另提供手机浏览器可直接打开并实际操作的网页链接；当前触控与手机性能尚未验收，Clide 是候选托管。先完成游戏再发布，具体缺口见 [手机网页交付](docs/MOBILE_WEB_DELIVERY.md)。

当前 0.6.0 已接通 S01—S12 功能白盒，另保留三条历史验证入口。居民和同伴按安全条件与实际到位自行行动，亲手操作仍需玩家输入。2026-10-31 本轮已合回 main：13 套正式人物、共享行走与 NPC AK、首批 8 件生成场景道具、175 条配音、11 段音乐及18个效果音。最终 562 项回归和构建通过；新资产实景、连续动作、约一小时首通及 Windows 实机仍待验收。

2026-10-31 备用候选已加入触屏、GLB加载与共享资源管理、实际AK-47、程序化间接反射、S12护航和真实人物骨架审计。不同检查合计320项有通过记录（包括6项超时后的原条件重试），并已实际观察桌面瞄准、横屏局部触控流程和修正后的竖屏持枪。S12机体可读性、完整首通、真机多指和Windows运行仍待验，未发布。范围见 [运行资产接入](docs/IMPORTED_ASSET_RUNTIME.md) 与 [本轮证据](artifacts/asset-runtime-evidence.md)。

## 运行候选

本轮运行实现为 `83da4a8`，主线的 245 项构建文件与被测备用候选一致。后来保存的开场与章节桥接候选另通过76项专项，尚未接入主战役。证据见 [本轮整合](artifacts/asset-integration/README.md)，之后按 [缺口表](docs/INTEGRATION_GAPS.md) 决定备用版补齐顺序。新一批地图与动作、全程实机和目标设备验收仍独立记录。

```sh
npm ci
npm run dev
```

浏览器入口 `http://127.0.0.1:5188`。桌面容器用 `npm run build` 后 `npm run desktop`；Windows 候选打包用 `npm run package:win`。实际覆盖与限制见 [构建说明](build/BUILD_BRIEF.md) 和 [当前验证记录](artifacts/autonomy-finale-evidence.md)。此前转接门／侧翼见 [0.4 记录](artifacts/transfer-evidence.md)，序章与北闸见 [0.3 记录](artifacts/opening-evidence.md)；三白盒与 S03／S04 的操作证据分别保存在 [白盒记录](artifacts/final-evidence.md)、[0.2 记录](artifacts/chapter-evidence.md)。

WASD 移动，Shift 冲刺，C 蹲伏，Space 跳跃，鼠标观察，左键／F 射击，右键瞄准，R 换弹，E 亲手交互，Q 请求同伴掩护（S10），Esc 暂停。方向键提供转向替代；Enter 只跳过允许的演出。暂停中可重试检查点、重开、调整音量／灵敏度与减少晃动。

主菜单“继续”恢复连续章节最近的检查点；独立验证场景使用分开的存档槽。“重开本场”重置当前段落，“从序章重新开始”重置这段连续流程。存档使用当前浏览器／Electron用户目录的本机存储；不同端口、浏览器和桌面容器不共享存档。生产版没有跨设备同步或导入导出；开发文件入口只做隔离的检查点验收。后续正式资产与发布版本仍需持续维护迁移策略。

## 当前推进约定

2026-10-30 用户选择尽可能覆盖三条验证线：序章 S01—S02、北闸 E04、S08—S11 人物取舍与协作演出。先共用一套输入、弹丸、任务、人物和演出接口，通过后扩展剩余战役；具体顺序见项目方案。验证线是开发步骤，不替代完整产品范围。

日常工作在 `main`。大改或并行工作前，先整理并提交主线，再将最新 `main` 同步到备用工作树的 `codex/vibehack06` 分支；分支验证通过后合回主线并检查整合结果。

用户已授权架构完成后持续制作，并允许占位资产先行。正式新资产先由 ImageGen 制作概念图，再进入 Tripo／Hyper3D 或 Dot 云端 Blender；先复用适合本作的已有素材。

2026-10-31 当前顺序：S01—S12 功能白盒已接通，先合并现有模型、音频与反馈修正，再梳理备用版缺口；手机新增优化后移。美术窗口继续已审资产和动作制作，声音窗口整合用户批准的整批配音。新设计仍先提交概念图、文字及空间方案审查，再统一生产。
