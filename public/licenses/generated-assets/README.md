# 原创概念与生成资产来源摘要

本摘要记录《重返木卫三》本轮已接入的 13 套人物、8 件场景道具及共用行走片段。来源为本地制作清单与已记录授权；本轮未查询外网或重新进行法律审查，不决定游戏整体许可证，也不把生成输出统一称为 CC0。

[manifest.json](manifest.json) 逐项保存资产名称、生成平台、概念输入文件名与 SHA-256、原始 GLB 摘要和运行 GLB 摘要。人物使用 Tripo；场景道具使用 Tripo／Hyper3D。原创概念由项目以 ImageGen 制作，并按生产记录完成设计与输入审查。概念图片和供应商原件仍在制作存档，页面不依赖它们加载。

原始 GLB 保留不改；本轮运行副本的内嵌纹理最长边缩至 1024，几何、UV、材质槽和骨架数据保持。因此源与运行 SHA 分开记录。人物站姿／行走的本地校准和场景等比放置属于项目适配，不是供应商提供完整表演的证明。

仅导出必要字段，不含账户、凭证、临时下载 URL、服务任务原响应或绝对本机路径。新生产但尚未接入的模型不列入这份清单。文件与代码整合不等于实际画面、碰撞接触、手机或 Windows 验收。
